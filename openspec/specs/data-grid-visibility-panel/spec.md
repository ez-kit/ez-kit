# data-grid-visibility-panel Specification

## Purpose

Определяет строку колоночной панели data-grid как точку интеграции UI-кита: как кит рисует строку
своим элементом, когда строка участвует в перетаскивании и как панель остаётся доступной и
управляемой с клавиатуры во время перетаскивания.

## Requirements

### Requirement: Строка панели рендерится элементом кита

Когда `children` у `DataGridVisibilityItem` — функция, компонент MUST NOT рендерить собственных
DOM-элементов. Функция MUST получить `itemProps` с `ref`, `data-slot="column-visibility-item"` и
`data-column-id`. Элемент, на который кит развернул `itemProps`, MUST быть элементом, который
двигает перетаскивание.

#### Scenario: Строка без обёртки

- **WHEN** кит рендерит строку через функцию-ребёнка и разворачивает `itemProps` на свой элемент
- **THEN** в DOM ровно один элемент с `data-slot="column-visibility-item"` на колонку
- **AND** у этого элемента нет родителя, созданного `DataGridVisibilityItem`

#### Scenario: Перетаскивание через элемент кита

- **WHEN** в гриде с drag-адаптером и включённым перетаскиванием панели пользователь тащит строку
  за грип, подключённый через `handleProps`, на другую строку
- **THEN** порядок колонок меняется так же, как у панели в режиме `ReactNode`
- **AND** `ordering.column.onChange` вызывается ровно один раз

### Requirement: Грип доступен только у перетаскиваемой строки

Функция-ребёнок MUST получить `handleProps` с `ref` активатора, когда строку можно перетащить,
и `null` во всех остальных случаях: нет drag-адаптера, панель не предлагает перетаскивание
(`visibilityMenu: 'step'`), колонка заблокирована (`ordering: false`), или компонент
отрендерен вне грида.

#### Scenario: Нет адаптера

- **WHEN** грид без drag-адаптера рендерит панель через функцию-ребёнка
- **THEN** `handleProps` равен `null` у каждой строки

#### Scenario: Заблокированная колонка

- **WHEN** в гриде с адаптером колонка объявлена с `ordering: false`
- **THEN** её строка получает `handleProps: null`
- **AND** перетаскивание остальных строк панели продолжает работать

#### Scenario: Перетаскивание панели выключено

- **WHEN** в гриде с адаптером задано `ordering.column.visibilityMenu: 'step'`
- **THEN** `handleProps` равен `null` у каждой строки

### Requirement: Состояние перетаскивания доступно киту

Пока строку тащат, функция-ребёнок MUST получить `isDragging: true`, а `itemProps` MUST
содержать `data-column-dragging="true"`. В остальное время `isDragging` MUST быть `false`, а
атрибут MUST отсутствовать.

#### Scenario: Во время перетаскивания

- **WHEN** пользователь взял строку и ещё не отпустил её
- **THEN** элемент кита этой строки несёт `data-column-dragging="true"`
- **AND** остальные строки этого атрибута не несут

### Requirement: Режим ReactNode не меняется

Когда `children` у `DataGridVisibilityItem` — не функция, компонент MUST рендерить строку так же,
как до этого изменения: собственный элемент с `data-slot="column-visibility-item"` и переданным
`className`.

#### Scenario: Существующий кит

- **WHEN** кит рендерит `DataGridVisibilityItem` с JSX-детьми и `className`
- **THEN** разметка и поведение перетаскивания совпадают с прежними

### Requirement: Коллекция кита не получает клавиш во время перетаскивания

Пакет MUST предоставлять киту способ подключить к элементу коллекции защиту, которая, пока
внутри этого элемента перетаскивается строка панели, не пускает события клавиатуры к
обработчикам коллекции. Перетаскивание с клавиатуры при этом MUST работать. Вне перетаскивания
защита MUST NOT влиять на клавиатуру.

#### Scenario: Одна стрелка — один шаг

- **WHEN** в панели-коллекции с подключённой защитой пользователь берёт строку с клавиатуры
  (`Space` на грипе), нажимает `ArrowDown` один раз и бросает (`Space`)
- **THEN** строка сдвигается ровно на одну позицию
- **AND** изменение порядка коммитится один раз

#### Scenario: Бросок не переключает видимость

- **WHEN** пользователь бросает строку клавишей `Space`
- **THEN** видимость ни одной колонки не меняется

#### Scenario: Навигация вне перетаскивания

- **WHEN** перетаскивания нет и фокус на строке коллекции
- **THEN** `ArrowDown` переводит фокус на следующую строку так, как это делает коллекция

### Requirement: Заблокированный элемент не становится активатором

Элемент, зарегистрированный для перетаскивания как заблокированный (строка панели или заголовок
колонки с `ordering: false`), MUST NOT получать от перетаскивания атрибуты активатора: `role`,
`tabindex`, `aria-roledescription`, `aria-describedby`, `aria-pressed`, `aria-grabbed`,
`aria-disabled`. Его место в порядке и смещение соседей при перетаскивании MUST сохраняться.

#### Scenario: Строка панели

- **WHEN** открыта панель с адаптером и колонкой `ordering: false`
- **THEN** строка этой колонки не несёт ни одного из перечисленных атрибутов от перетаскивания
- **AND** не становится лишней остановкой `Tab`

#### Scenario: Заголовок колонки

- **WHEN** в гриде с адаптером и перетаскиванием заголовков есть колонка `ordering: false`
- **THEN** её `th` не получает `role="button"` и `aria-pressed`

#### Scenario: Соседи смещаются как раньше

- **WHEN** пользователь тащит строку панели мимо заблокированной строки
- **THEN** результат перетаскивания совпадает с прежним поведением

### Requirement: Колоночная панель HeroUI — коллекция react-aria

Колоночная панель кита HeroUI (когда задан `ordering.column.visibilityMenu`) MUST рендерить
строки как строки сетки-коллекции (`role="grid"` / `role="row"`) без обёрток вокруг строки.
Видимость колонки MUST переключаться выбором строки. Колонка без права скрытия MUST оставаться в
списке, её переключатель MUST быть недоступен, а перемещения MUST работать.

#### Scenario: Переключение видимости

- **WHEN** пользователь нажимает на название скрытой колонки в панели
- **THEN** колонка появляется в таблице

#### Scenario: Колонка без права скрытия

- **WHEN** у колонки `canHide` равен `false`
- **THEN** её строка видна в панели, переключатель недоступен
- **AND** стрелки перемещения (если панель их предлагает) работают

#### Scenario: Доступность открытой панели

- **WHEN** панель открыта в гриде с адаптером и заблокированной колонкой
- **THEN** axe не находит нарушений в строках панели

#### Scenario: Простой переключатель Columns

- **WHEN** `ordering.column.visibilityMenu` не задан
- **THEN** кит HeroUI рендерит переключатель видимости как меню, как раньше
