# data-grid-disabled-features Specification

## Purpose

Определяет, как ведёт себя фича data-grid, выключенная в конфиге, когда её модель строк
зарегистрирована в наборе фич: какие строки видны, что происходит с её состоянием, как она
включается и выключается на лету и что грид сообщает разработчику и вспомогательным технологиям.

## Requirements

### Requirement: Грид без клиентской пагинации показывает все строки

Грид, у которого пагинация не включена, SHALL возвращать и рендерить все строки набора, даже
если в наборе фич зарегистрирована модель среза по страницам. Пагинация считается не включённой,
когда `pagination` не задан, равен `false` или задан объектом с `enabled: false`.

#### Scenario: pagination не задан, полный набор фич

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками данных и без `pagination`
- **THEN** модель строк таблицы содержит 50 строк
- **AND** тело таблицы рендерит 50 строк, элементов пагинации нет

#### Scenario: pagination: false

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками и `pagination: false`
- **THEN** модель строк таблицы содержит 50 строк

#### Scenario: pagination: { enabled: false } с настройками

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками и `pagination: { enabled: false, pageSize: 5 }`
- **THEN** модель строк таблицы содержит 50 строк

#### Scenario: useDataGrid и внешний экземпляр

- **WHEN** экземпляр получен из `useDataGrid({ data, columns })` без `pagination` и передан в `<DataGrid table={table} />`
- **THEN** экземпляр возвращает все строки, и грид рендерит все строки

#### Scenario: Готовый DataGrid кита

- **WHEN** готовый `DataGrid` из `@ez-kit/data-grid-shadcn` или `@ez-kit/data-grid-heroui` рендерится с 25 строками и без `pagination`
- **THEN** видны все 25 строк

#### Scenario: Набор без модели среза

- **WHEN** грид создан с набором без модели среза, 50 строками и без `pagination`
- **THEN** модель строк таблицы содержит 50 строк, как и до изменения

### Requirement: Включённые режимы пагинации не меняются

Клиентская, серверная и бесконечная пагинация SHALL вести себя так же, как до изменения, при
одном и том же наборе фич.

#### Scenario: Клиентская пагинация

- **WHEN** грид создан с `allDataGridFeatures`, 25 строками и `pagination: { pageSize: 10 }`
- **THEN** модель строк содержит 10 строк, `getRowCount()` равен 25, `getPageCount()` равен 3

#### Scenario: Серверная пагинация

- **WHEN** грид создан с `allDataGridFeatures`, 10 строками и `pagination: { manual: true, pageSize: 10, rowCount: 100 }`
- **THEN** модель строк содержит 10 строк, `getRowCount()` равен 100, `getPageCount()` равен 10

#### Scenario: Бесконечная пагинация

- **WHEN** грид создан с `allDataGridFeatures`, 25 строками и `pagination: { mode: 'infinite', pageSize: 10 }`
- **THEN** модель строк содержит 25 строк

### Requirement: Засеянная пагинация при выключенной пагинации не режет строки

Засеянный `initialState.pagination` при не включённой пагинации SHALL оставаться в состоянии
таблицы без изменений и SHALL NOT влиять на видимые строки.

#### Scenario: Засеянный pageIndex

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками, без `pagination` и с `initialState.pagination: { pageIndex: 2, pageSize: 10 }`
- **THEN** модель строк содержит 50 строк, первая из них — первая строка данных
- **AND** состояние таблицы `pagination` равно `{ pageIndex: 2, pageSize: 10 }`

### Requirement: Выключенная группировка не группирует строки

Засеянное состояние группировки при не включённой `grouping` SHALL оставаться в состоянии
таблицы и SHALL NOT группировать строки.

#### Scenario: Засеянная группировка без grouping

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками, без `grouping` и с `initialState.grouping: ['age']`
- **THEN** модель строк содержит 50 несгруппированных строк
- **AND** состояние таблицы `grouping` равно `['age']`

#### Scenario: Включённая группировка не меняется

- **WHEN** грид создан с `grouping: true` и `initialState.grouping: ['age']`
- **THEN** строки сгруппированы по `age`

### Requirement: Выключенная колоночная фильтрация не фильтрует строки

Засеянные колоночные фильтры при не включённой `filtering` SHALL оставаться в состоянии таблицы
и SHALL NOT отбрасывать строки. Глобальный поиск при включённом `globalFiltering` SHALL
фильтровать строки как прежде.

#### Scenario: Засеянный колоночный фильтр без filtering

- **WHEN** грид создан с `allDataGridFeatures`, 50 строками, без `filtering` и с `initialState.columnFilters`, которому соответствуют 9 строк
- **THEN** модель строк содержит 50 строк
- **AND** состояние таблицы `columnFilters` сохраняет засеянное значение

#### Scenario: Глобальный поиск при выключенных колоночных фильтрах

- **WHEN** грид создан без `filtering`, с `globalFiltering: true`, засеянным колоночным фильтром и поисковой строкой, которой соответствуют 5 строк
- **THEN** модель строк содержит ровно 5 строк, совпавших с поиском, без учёта колоночного фильтра

#### Scenario: Включённая фильтрация не меняется

- **WHEN** грид создан с `filtering: true` и `initialState.columnFilters`, которому соответствуют 9 строк
- **THEN** модель строк содержит 9 строк

### Requirement: Включение и выключение фичи на лету

Смена конфига фичи на живом экземпляре, без перемонтирования, SHALL сразу применять или снимать
её эффект на строки. Сохранённое состояние SHALL вступать в силу при включении.

#### Scenario: Пагинация выключена, включена и снова выключена

- **WHEN** грид с 50 строками рендерится без `pagination`, затем с `pagination: { pageSize: 10 }`, затем снова без `pagination`
- **THEN** тело таблицы рендерит 50, затем 10, затем 50 строк

#### Scenario: Сохранённый pageIndex вступает в силу при включении

- **WHEN** грид без `pagination` засеян `initialState.pagination: { pageIndex: 2, pageSize: 10 }`, и затем ему включают `pagination: true`
- **THEN** видны строки с 21-й по 30-ю

#### Scenario: Возврат из бесконечного и серверного режима в клиентский

- **WHEN** конфиг экземпляра меняется с `mode: 'infinite'` или `manual: true` на `pagination: { pageSize: 10 }`, в том числе через `setOptions` со слиянием с прежними опциями
- **THEN** модель строк содержит 10 строк, а итог строк считается по данным, без прежнего `rowCount`

#### Scenario: Группировка и фильтрация включаются на лету

- **WHEN** грид с засеянными `grouping` и `columnFilters` рендерится без `grouping` и `filtering`, затем с ними
- **THEN** сначала строки не сгруппированы и не отфильтрованы, затем сгруппированы и отфильтрованы по сохранённому состоянию

### Requirement: Выключенные сортировка, поиск, раскрытие и закрепление строк не меняют строки

Засеянное состояние сортировки, глобального поиска, раскрытия и закрепления строк при не
включённой соответствующей фиче SHALL NOT менять порядок, состав или расположение
отрендеренных строк.

#### Scenario: Засеянная сортировка без sorting

- **WHEN** грид создан без `sorting` и с `initialState.sorting`
- **THEN** строки идут в порядке данных

#### Scenario: Засеянный поиск без globalFiltering

- **WHEN** грид создан без `globalFiltering` и с непустым `initialState.globalFilter`
- **THEN** видны все строки

#### Scenario: Засеянное раскрытие без expanding

- **WHEN** грид с вложенными данными создан без `expanding` и `grouping` и с `initialState.expanded: true`
- **THEN** вложенные строки не рендерятся

#### Scenario: Засеянное закрепление строк без pinning

- **WHEN** грид создан без закрепления строк и с `initialState.rowPinning`, называющим строку
- **THEN** эта строка рендерится на своём месте в порядке данных

### Requirement: Предупреждение о засеве выключенной фичи

В режиме разработки засев состояния, меняющего строки, при не включённой фиче SHALL давать одно
предупреждение на срез, называющее засев и фичу. В production SHALL NOT быть предупреждений.
Предупреждение SHALL NOT появляться для включённой фичи, для контролируемого `state` и для
состояния, которое засеяло само ядро.

#### Scenario: Засеянная пагинация

- **WHEN** грид создан без `pagination` и с `initialState.pagination`
- **THEN** в development выводится одно предупреждение, называющее `initialState.pagination` и `pagination`

#### Scenario: Засеянные фильтры, группировка, сортировка и поиск

- **WHEN** грид создан с `initialState.columnFilters`, `.grouping`, `.sorting` или `.globalFilter`, а соответствующая фича (`filtering`, `grouping`, `sorting`, `globalFiltering`) не включена
- **THEN** для каждого такого среза выводится одно предупреждение, называющее засев и фичу

#### Scenario: Засеянное раскрытие

- **WHEN** грид создан с `initialState.expanded`, а не включены ни `expanding`, ни `grouping`
- **THEN** выводится одно предупреждение
- **AND** при включённой `grouping` и выключенном `expanding` предупреждения нет, потому что раскрытие управляет группами

#### Scenario: Засеянное закрепление строк

- **WHEN** грид создан с `initialState.rowPinning`, а закрепление строк не включено
- **THEN** выводится одно предупреждение

#### Scenario: Пагинация без засева

- **WHEN** грид создан без `pagination` и без `initialState.pagination`
- **THEN** предупреждения о пагинации нет

#### Scenario: Включённая фича

- **WHEN** грид создан с `filtering: true` и `initialState.columnFilters`
- **THEN** предупреждения о колоночных фильтрах нет

#### Scenario: Контролируемое состояние

- **WHEN** грид получает `state.columnFilters` без включённой `filtering`
- **THEN** предупреждения нет

### Requirement: ARIA-итог грида без пагинации

Грид без включённой пагинации SHALL сообщать вспомогательным технологиям, что в DOM весь набор
строк, при любом наборе фич: без `aria-rowcount` и `aria-rowindex`. Статус числа строк SHALL
объявлять полный итог.

#### Scenario: Полный набор фич

- **WHEN** грид с `allDataGridFeatures` и 12 строками рендерится без `pagination`
- **THEN** у таблицы нет `aria-rowcount`, у строк нет `aria-rowindex`

#### Scenario: Набор без модели среза

- **WHEN** грид с набором без модели среза и 12 строками рендерится без `pagination`
- **THEN** у таблицы нет `aria-rowcount`, у строк нет `aria-rowindex`

#### Scenario: Засеянный pageIndex не сдвигает индексы

- **WHEN** грид без `pagination` засеян `initialState.pagination: { pageIndex: 2 }`
- **THEN** у строк нет `aria-rowindex`

#### Scenario: Статус числа строк

- **WHEN** грид с 12 строками рендерится без `pagination`
- **THEN** статус числа строк объявляет 12

#### Scenario: Клиентская, серверная и бесконечная пагинация

- **WHEN** грид рендерится с клиентской, серверной или бесконечной пагинацией
- **THEN** `aria-rowcount` и `aria-rowindex` такие же, как до изменения
