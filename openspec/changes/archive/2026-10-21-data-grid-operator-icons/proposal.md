# Proposal

## Why

Переключатель оператора в фильтре колонки стоит отдельной строкой под полем («Contains ˅»). Он
добавляет строку к высоте шапки, а в гриде, где операторы есть не у всех колонок, низ фильтров
перестаёт совпадать: под одними полями переключатель, под другими пустота. Рядом нашлась
ошибка в реестре операторов: `filtering.operators.items` таблицы обещает переопределять встроенные
операторы, но для встроенных типов ячеек переопределение не доходит ни до одной колонки.

## What Changes

- Переключатель оператора переезжает в ту же строку, что и поле фильтра, первым элементом слева,
  и становится кнопкой. По умолчанию кнопка показывает подпись текущего оператора, обрезанную по
  ширине, а если оператору задана иконка, — иконку. По нажатию открывается меню: иконка (если
  есть) и подпись каждого оператора. Отдельной строки под полем больше нет ни в одной ветке фильтра:
  текст, cell-type, `filtering.component`, `between`, мультивыбор, операторы без значения.
- `FilterOperatorDef` получает необязательное `icon?: unknown` (в React — `ReactNode`, как у
  `SelectItem.icon`).
- Core экспортирует `DEFAULT_OPERATOR_ICONS`: готовый набор юникод-знаков встроенных операторов
  (`=`, `≠`, `>`, `≥`, `<`, `≤`, `*a*`, `a*`, `*a`, `↔`, `∈`, `∉`, `∅`, `≠∅`). Сам по себе он
  ничего не включает: знаки появляются, только если передать его в `icons.operators`. По
  умолчанию грид знаков не показывает — это решение #63 («глифы нечитаемы без легенды»), и
  change его не пересматривает.
- Новая опция верхнего уровня `icons: { operators: Partial<Record<FilterOperatorId, ReactNode>> }`
  в `UseDataGridConfig`. Она ничего не включает и проходит через все слои опций:
  `createDataGrid({ defaults })`, `DataGridOptionsProvider`, конфиг экземпляра. Слои сливаются по
  ключам.
- Иконка оператора выбирается так: `def.icon` > `icons.operators[id]`. Оператор без иконки
  показывает в кнопке свою подпись, обрезанную по ширине.
- Модель фильтра (`FilterModel.operators`) отдаёт операторы с итоговой иконкой, чтобы своя панель
  на модели показывала те же иконки, что и шапка.
- **BREAKING (поведение):** оператор из `filtering.operators.items` таблицы с id встроенного
  оператора теперь заменяет встроенный во всех колонках всех типов ячеек, включая наборы по
  умолчанию (`operators: true`). Раньше такая запись молча игнорировалась. Переопределённый
  оператор сохраняет подпись автора: словарь её не подменяет.
- **BREAKING (кит-слот, визуально):** кнопка оператора — триггер меню, а не combobox. Тесты и
  e2e, которые искали `combobox` по имени `Filter operator`, ищут кнопку. Пропсы
  `OperatorSelectProps` не меняются, поэтому сторонний кит продолжает компилироваться.

## Capabilities

### New Capabilities

- `data-grid-filter-operators`: реестр операторов и их иконки. Переопределение встроенного
  оператора через реестр таблицы, подпись переопределённого оператора, источник иконки и порядок
  выбора между источниками, опция `icons.operators` и её слои.
- `data-grid-operator-control`: как фильтр с операторами показывает оператор. Кнопка в строке
  поля, fallback на подпись, меню, accessible name, одна высота строки у всех веток фильтра.

### Modified Capabilities

- `data-grid-filter-model`: операторы модели несут итоговую иконку; правило «модель без
  React-элементов» уточняется, потому что иконка оператора (как и иконка варианта из `getItem`)
  может быть React-элементом.

## Impact

- `@ez-kit/data-grid-core`: `FilterOperatorDef.icon`, `DEFAULT_OPERATOR_ICONS`,
  `buildOperatorRegistry` / `resolveColumnOperators` / `resolve-filtering.ts` (реестр хранит
  переопределения таблицы отдельно), `localizeOperators` (не трогает переопределённые),
  докстринг `TableOperatorsConfig`, новое сообщение для имени кнопки оператора.
- `@ez-kit/data-grid-react`: `UseDataGridConfig.icons`, `DataGridDefaultOptions`,
  `filter-model.ts` (иконки в модели), `render-filter-input.tsx` (раскладка всех веток),
  `active-filters-bar.tsx` (тот же резолвер подписей), test-utils kit.
- Киты shadcn и heroui: `OperatorSelect` переписан как кнопка-триггер с меню;
  `[data-slot='filter-control']` в обоих `styles.css` (сейчас растягивает первый элемент строки,
  которым станет кнопка).
- Документация: `filtering/operators.mdx` (новая раскладка, `icons`, переопределение встроенных),
  таблицы опций и счётчики в `page-type-map.ts`, e2e `localization/messages.spec.ts`.
- Changeset `minor` для `@ez-kit/data-grid-core` и `@ez-kit/data-grid-react`; shadcn-кит в
  changeset не попадает.
