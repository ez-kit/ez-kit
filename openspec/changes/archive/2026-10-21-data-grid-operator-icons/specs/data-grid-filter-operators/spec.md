# Spec Delta

## Purpose

Определяет, какие операторы фильтра получает колонка, когда таблица регистрирует свои, и откуда
каждый оператор берёт иконку, которую показывает его переключатель вместо подписи.

## ADDED Requirements

### Requirement: Реестр таблицы переопределяет встроенный оператор

Оператор из `filtering.operators.items` таблицы, чей id совпадает с id встроенного оператора, MUST
заменять встроенный во всех колонках всех типов ячеек: и в наборе по умолчанию (`operators: true`
или наследование `true` от таблицы), и там, где колонка называет этот id в своём `items`. Логика
фильтрации и подпись берутся из переопределения.

#### Scenario: Переопределение доходит до набора по умолчанию

- **WHEN** таблица объявлена с `filtering: { operators: { items: [{ id: 'contains', label: 'Похоже на', filterFn: accentInsensitive }] } }`, а текстовая колонка `name` — с `filtering: { operators: true }`
- **THEN** оператор `contains` колонки `name` фильтрует через `accentInsensitive`

#### Scenario: Переопределение доходит до колонки, которая называет id

- **WHEN** таблица переопределяет `contains`, а колонка объявлена с `filtering: { operators: { items: ['contains', 'equals'] } }`
- **THEN** оператор `contains` этой колонки — переопределённый, а `equals` — встроенный для её типа ячейки

#### Scenario: Переопределение действует для всех типов ячеек

- **WHEN** таблица переопределяет `equals`, а в гриде есть колонки типов `text`, `number` и `date` с операторами
- **THEN** у всех трёх колонок `equals` фильтрует через переопределение

#### Scenario: Без переопределения наборы не меняются

- **WHEN** таблица регистрирует только оператор `fuzzy`
- **THEN** операторы колонок со встроенными типами ячеек совпадают с их наборами по умолчанию

### Requirement: Подпись переопределённого оператора не локализуется

Оператор, пришедший из реестра таблицы, MUST показывать подпись, заданную его автором, даже если
его id есть в словаре грида (`messages.operators`). Встроенный оператор, не переопределённый
таблицей, MUST получать подпись из словаря, как и раньше.

#### Scenario: Автор переопределения сохраняет свою подпись

- **WHEN** таблица переопределяет `contains` с подписью `Похоже на`, а словарь грида называет `contains` «Содержит»
- **THEN** переключатель оператора и чип активного фильтра показывают `Похоже на`

#### Scenario: Встроенный оператор берёт подпись из словаря

- **WHEN** таблица ничего не переопределяет, а словарь называет `contains` «Содержит»
- **THEN** у `contains` подпись «Содержит»

### Requirement: Встроенные операторы по умолчанию показываются подписью

Встроенный оператор MUST NOT получать иконку, пока её не задали на операторе или опцией
`icons.operators`: по умолчанию переключатель показывает подпись оператора.

#### Scenario: Без настройки знаков нет

- **WHEN** у числовой колонки текущий оператор `greaterOrEqual`, и иконки нигде не заданы
- **THEN** кнопка оператора показывает подпись `Greater than or equal`, а не `≥`

### Requirement: Готовый набор знаков встроенных операторов

Пакет MUST экспортировать `DEFAULT_OPERATOR_ICONS` — юникод-знак для каждого встроенного
оператора, один для всех типов ячеек. Набор MUST ничего не менять сам по себе и MUST
подходить как значение `icons.operators`.

#### Scenario: Знаки набора

- **WHEN** потребитель читает `DEFAULT_OPERATOR_ICONS`
- **THEN** он содержит `contains` `*a*`, `startsWith` `a*`, `endsWith` `*a`, `equals` `=`, `notEquals` `≠`, `greaterThan` `>`, `greaterOrEqual` `≥`, `lessThan` `<`, `lessOrEqual` `≤`, `between` `↔`, `in` `∈`, `notIn` `∉`, `isEmpty` `∅`, `isNotEmpty` `≠∅`

#### Scenario: Знаки включаются одной опцией

- **WHEN** `createDataGrid({ defaults: { icons: { operators: DEFAULT_OPERATOR_ICONS } } })`, а у колонки типа `date` текущий оператор `greaterThan` с подписью «After»
- **THEN** кнопка оператора показывает `>`

### Requirement: Иконку можно задать на операторе

`FilterOperatorDef` MUST принимать необязательное `icon`. В React-адаптере это любое значение,
которое React может отрендерить: строка или элемент. Иконка, заданная на операторе, MUST иметь
приоритет над всеми остальными источниками.

#### Scenario: Пользовательский оператор со своей иконкой

- **WHEN** колонка предлагает оператор `{ id: 'fuzzy', label: 'Fuzzy', icon: '≈', filterFn }`
- **THEN** при текущем `fuzzy` кнопка оператора показывает `≈`

#### Scenario: Иконка оператора важнее опции грида

- **WHEN** колонка предлагает inline-оператор `{ id: 'contains', …, icon: <A/> }`, а грид задаёт `icons: { operators: { contains: <B/> } }`
- **THEN** кнопка показывает `<A/>`

### Requirement: Иконки операторов задаются опцией грида

Грид MUST принимать опцию `icons.operators` — объект `id оператора → иконка`. Иконка из неё
MUST уступать иконке, заданной на операторе. Опция MUST NOT включать фильтрацию, операторы или
любую другую функцию грида.

#### Scenario: Опция задаёт иконку встроенного оператора

- **WHEN** грид объявлен с `icons: { operators: { greaterOrEqual: <ArrowUpRight/> } }`, а у колонки текущий оператор `greaterOrEqual`
- **THEN** кнопка оператора показывает `<ArrowUpRight/>`

#### Scenario: Опция не включает операторы

- **WHEN** `createDataGrid({ defaults: { icons: { operators: { equals: '==' } } } })`, а грид из этого бандла не объявляет `filtering`
- **THEN** у грида нет ни фильтров, ни переключателей операторов

### Requirement: Опция иконок проходит через слои опций

`icons.operators` MUST задаваться в `createDataGrid({ defaults })`, в `DataGridOptionsProvider` и в
конфиге экземпляра. Слои MUST сливаться по id оператора: верхний слой заменяет иконку только тех
операторов, которые он называет, остальные остаются из нижнего.

#### Scenario: Приложение заменяет одну иконку кита

- **WHEN** кит задаёт в `createDataGrid({ defaults })` иконки для `equals` и `contains`, а `DataGridOptionsProvider` приложения задаёт только `contains`
- **THEN** у `equals` иконка кита, у `contains` — приложения

#### Scenario: Экземпляр важнее провайдера

- **WHEN** провайдер задаёт иконку `equals`, а конфиг экземпляра — другую иконку `equals`
- **THEN** кнопка показывает иконку экземпляра
