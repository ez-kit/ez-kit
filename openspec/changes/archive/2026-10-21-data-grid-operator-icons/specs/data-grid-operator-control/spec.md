# Spec Delta

## Purpose

Определяет, как фильтр с операторами показывает и переключает текущий оператор, чтобы
переключатель не добавлял строку к высоте шапки и одинаково выглядел во всех видах фильтра.

## ADDED Requirements

### Requirement: Оператор в одной строке с полем

Фильтр с операторами MUST показывать переключатель оператора в той же строке, что и контрол
значения, первым элементом в направлении письма. Под контролом значения фильтр MUST NOT
показывать отдельную строку с оператором. Правило действует для всех видов контрола: текстовое
поле, фильтр cell-type, `filtering.component`, диапазон `between` и мультивыбор `in` / `notIn`.

#### Scenario: Текстовый фильтр

- **WHEN** колонка `name` объявлена с `filtering: { operators: true }`
- **THEN** переключатель оператора и поле фильтра находятся в одной строке, переключатель — перед полем

#### Scenario: Мультивыбор

- **WHEN** у колонки типа `select` с операторами текущий оператор `in`
- **THEN** переключатель оператора и мультивыбор находятся в одной строке

#### Scenario: Диапазон

- **WHEN** у числовой колонки текущий оператор `between`
- **THEN** переключатель оператора и оба поля диапазона находятся в одной строке

### Requirement: Оператор без значения занимает ту же строку

Если текущий оператор не требует значения (`requiresInput: false`), фильтр MUST показывать
переключатель оператора в той же строке и вместо поля — подпись этого оператора, так что
высота строки не меняется при переключении на такой оператор и обратно.

#### Scenario: Переход на «пусто»

- **WHEN** пользователь выбирает у колонки оператор `isEmpty`
- **THEN** строка фильтра содержит переключатель и подпись оператора, поле значения не показывается

### Requirement: Переключатель показывает иконку текущего оператора

Переключатель оператора MUST быть кнопкой, которая показывает иконку текущего оператора. Если у
оператора нет иконки ни из одного источника, кнопка MUST показывать его подпись, обрезанную по
ширине кнопки. Полная подпись при этом MUST оставаться доступной в accessible name и в меню.

#### Scenario: Оператор с иконкой

- **WHEN** грид объявлен с `icons: { operators: { equals: '=' } }`, а текущий оператор колонки `equals`
- **THEN** кнопка показывает `=`

#### Scenario: Оператор без иконки

- **WHEN** иконки нигде не заданы, а текущий оператор текстовой колонки `contains`
- **THEN** кнопка показывает текст `Contains`, обрезанный по её ширине

### Requirement: Меню операторов

Нажатие на переключатель MUST открывать меню со всеми операторами колонки. Каждый пункт MUST
показывать иконку оператора (если она есть) и его подпись. Текущий оператор MUST быть отмечен
как выбранный. Выбор пункта MUST менять оператор по тем же правилам смены оператора, что и
раньше.

#### Scenario: Пункты меню

- **WHEN** грид объявлен с `icons: { operators: DEFAULT_OPERATOR_ICONS }`, и пользователь открывает переключатель числовой колонки
- **THEN** меню содержит пункты вида `≥ Greater than or equal`, а текущий оператор отмечен

#### Scenario: Пункты меню без иконок

- **WHEN** иконки нигде не заданы, и пользователь открывает переключатель числовой колонки
- **THEN** пункты меню показывают только подписи, а текущий оператор отмечен

#### Scenario: Выбор оператора

- **WHEN** пользователь выбирает в меню `between` у числовой колонки со значением `10`
- **THEN** фильтр колонки получает оператор `between` с пустым диапазоном, как при прежнем переключателе

### Requirement: Accessible name переключателя

Accessible name кнопки оператора MUST включать подпись текущего оператора и MUST строиться
сообщением `messages.filtering.operatorTrigger({ label })`. Дефолтный английский словарь MUST
давать `Filter operator: <label>`. Меню MUST называться `messages.filtering.operator`.

#### Scenario: Имя по умолчанию

- **WHEN** у колонки текущий оператор `contains`, а словарь дефолтный
- **THEN** у кнопки оператора accessible name `Filter operator: Contains`

#### Scenario: Локализованное имя

- **WHEN** словарь задаёт `filtering.operatorTrigger: ({ label }) => \`Оператор: ${label}\``, а `contains` подписан «Содержит»
- **THEN** у кнопки оператора accessible name `Оператор: Содержит`

### Requirement: Колонка без операторов не получает переключатель

Фильтр колонки без операторов MUST показывать только свой контрол значения, без кнопки
оператора и без места под неё.

#### Scenario: Колонка без операторов рядом с колонкой с операторами

- **WHEN** колонка `salary` объявлена с операторами, а `department` — без
- **THEN** у `department` нет кнопки оператора, а фильтры обеих колонок занимают одну строку одинаковой высоты
