# Spec Delta

## MODIFIED Requirements

### Requirement: Грип доступен только у перетаскиваемой строки

Функция-ребёнок MUST получить `handleProps` с `ref` активатора, когда строку можно перетащить,
и `null` во всех остальных случаях: нет drag-адаптера, панель не предлагает перетаскивание
(`visibilityMenu: 'step'`), колонка заблокирована (`ordering: false`), или компонент
отрендерен вне грида.

#### Scenario: Нет адаптера

- **WHEN** грид без drag-адаптера рендерит панель через функцию-ребёнка
- **THEN** `handleProps` равен `null` у каждой строки

#### Scenario: Заблокированная колонка

- **WHEN** в гриде с адаптером колонка объявлена с `ordering: false`
- **THEN** её строка получает `handleProps: null`
- **AND** перетаскивание остальных строк панели продолжает работать

#### Scenario: Перетаскивание панели выключено

- **WHEN** в гриде с адаптером задано `ordering.column.visibilityMenu: 'step'`
- **THEN** `handleProps` равен `null` у каждой строки
