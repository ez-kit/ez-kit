# Spec Delta

## Purpose

Подсвечивает отрисованные ячейки грида, чьё значение изменилось, чтобы пользователь замечал
обновления данных, пришедших по сокету или поллингу, и даёт приложению вызвать ту же подсветку
вручную.

## ADDED Requirements

### Requirement: Флэш включается на гриде и переопределяется на колонке

Опция грида `flashing` MUST включать автоматический флэш во всех колонках данных. Опция колонки
`flashing` MUST переопределять грид в обе стороны: `true` или объект включают колонку при
выключенном гриде, `false` выключает её при включённом. Без опции на гриде и на колонке флэша нет.

#### Scenario: Включено на гриде

- **WHEN** грид объявлен с `flashing: true`, а колонки `price` и `qty` — без `flashing`, и значения обеих изменились
- **THEN** обе ячейки флэшат

#### Scenario: Колонка выключена при включённом гриде

- **WHEN** грид объявлен с `flashing: true`, колонка `updatedAt` — с `flashing: false`, и её значение изменилось
- **THEN** ячейка `updatedAt` не флэшит

#### Scenario: Колонка включена при выключенном гриде

- **WHEN** у грида нет `flashing`, колонка `price` объявлена с `flashing: true`, и значения `price` и `qty` изменились
- **THEN** флэшит только ячейка `price`

### Requirement: Длительности задаются на гриде и переопределяются на колонке

Флэш MUST состоять из фазы заливки длительностью `flashDuration` и фазы затухания длительностью
`fadeDuration`; по умолчанию 500 и 1000 мс. Объект `flashing` колонки MUST накладываться на объект
грида по ключам; `flashing: true` на колонке MUST сохранять длительности грида.

#### Scenario: Длительность колонки поверх грида

- **WHEN** грид объявлен с `flashing: { flashDuration: 300, fadeDuration: 2000 }`, а колонка — с `flashing: { flashDuration: 100 }`
- **THEN** ячейка этой колонки флэшит с заливкой 100 мс и затуханием 2000 мс

#### Scenario: true на колонке не сбрасывает длительности грида

- **WHEN** грид объявлен с `flashing: { fadeDuration: 2000 }`, а колонка — с `flashing: true`
- **THEN** ячейка этой колонки затухает 2000 мс

### Requirement: Опция грида проходит через слои опций

`flashing` грида MUST приниматься в `defaults` бандла и провайдера опций и сливаться с конфигом
грида по правилам слоёв опций: объект поверх объекта — по ключам, `true` поверх объекта сохраняет
объект, `false` выключает флэш.

#### Scenario: Конфиг грида выключает флэш из defaults

- **WHEN** провайдер опций задаёт `defaults: { flashing: true }`, а грид объявлен с `flashing: false`
- **THEN** ни одна ячейка грида автоматически не флэшит

### Requirement: Ячейка флэшит при изменении своего значения

Отрисованная ячейка колонки с включённым флэшем MUST флэшить, когда значение колонки для её строки
отличается от значения, которое она показывала до этого. Ячейка с неизменившимся значением MUST NOT
флэшить.

#### Scenario: Изменилось одно значение

- **WHEN** грид с `flashing: true` получает новые `data`, где у строки `r1` поле `price` сменилось со 100 на 101, а остальные значения те же
- **THEN** флэшит только ячейка `r1` / `price`

#### Scenario: Новые объекты с теми же значениями

- **WHEN** грид с `flashing: true` получает новый массив `data` из новых объектов строк с теми же примитивными значениями
- **THEN** ни одна ячейка не флэшит

### Requirement: Даты сравниваются по времени, остальное — по колонке

Два значения `Date` MUST считаться равными, если равно их время. Остальные значения MUST
сравниваться по идентичности (`Object.is`), если у колонки не задан `flashing.equals`; заданный
`equals` MUST решать, изменилось ли значение.

#### Scenario: Новый объект Date с тем же временем

- **WHEN** колонка `createdAt` с флэшем получает новый объект `Date` с тем же временем
- **THEN** ячейка не флэшит

#### Scenario: equals колонки

- **WHEN** колонка `tags` объявлена с `flashing: { equals: (a, b) => a.join() === b.join() }` и получает новый массив `['a', 'b']` вместо прежнего `['a', 'b']`
- **THEN** ячейка не флэшит

#### Scenario: Массив без equals

- **WHEN** колонка `tags` с `flashing: true` без `equals` получает новый массив с теми же элементами
- **THEN** ячейка флэшит

### Requirement: Появление ячейки не флэшит

Ячейка MUST NOT флэшить при монтировании: на первом рендере грида, при появлении в окне
виртуализации, при смене страницы, фильтра или при добавлении строки. Ячейка, значение которой
изменилось, пока она не была отрисована, MUST при появлении показывать новое значение без флэша.

#### Scenario: Первый рендер

- **WHEN** грид с `flashing: true` рендерится впервые
- **THEN** ни одна ячейка не флэшит

#### Scenario: Строка изменилась вне окна виртуализации

- **WHEN** в виртуализированном гриде с `flashing: true` меняется значение строки вне окна, а затем пользователь прокручивает к ней
- **THEN** ячейка показывает новое значение и не флэшит

### Requirement: Флэш привязан к id строки

Сравнение значений MUST идти по id строки, а не по её позиции. В development грид MUST
предупреждать, если флэш включён, а id строк — индексы: `getRowId` не задан и у строк нет `id`.

#### Scenario: Сортировка с getRowId

- **WHEN** грид с `flashing: true` и `getRowId` меняет порядок строк сортировкой, а значения не меняются
- **THEN** ни одна ячейка не флэшит

#### Scenario: Флэш на индексных id

- **WHEN** грид в development объявлен с `flashing: true` без `getRowId`, а у строк нет поля `id`
- **THEN** грид выводит одно предупреждение о `getRowId`

#### Scenario: Строки с id

- **WHEN** грид объявлен с `flashing: true` без `getRowId`, а у строк есть поле `id`
- **THEN** предупреждения о `getRowId` нет

### Requirement: Ручной флэш по адресу

`table.flashCells(params)` MUST флэшить отрисованные ячейки, чья строка входит в `rowIds` и чья
колонка входит в `columnIds`; отсутствующий `rowIds` или `columnIds` означает «все» по этой оси.
Ручной флэш MUST работать при зарегистрированной фиче независимо от опции `flashing`.
Неотрисованные ячейки вызов MUST игнорировать.

#### Scenario: Флэш одной строки

- **WHEN** приложение вызывает `table.flashCells({ rowIds: ['r1'] })`
- **THEN** флэшат все отрисованные ячейки данных строки `r1` и только они

#### Scenario: Флэш колонки с выключенной автоматикой

- **WHEN** у грида и колонки `price` нет `flashing`, и приложение вызывает `table.flashCells({ columnIds: ['price'] })`
- **THEN** отрисованные ячейки `price` флэшат

#### Scenario: Длительности вызова

- **WHEN** приложение вызывает `table.flashCells({ rowIds: ['r1'], flashDuration: 50 })`
- **THEN** заливка ячеек `r1` длится 50 мс

### Requirement: Ячейка, появившаяся после вызова, его не повторяет

Ячейка, смонтированная после вызова `flashCells`, MUST NOT флэшить из-за этого вызова.

#### Scenario: Прокрутка после ручного флэша

- **WHEN** приложение вызывает `table.flashCells()` для всех ячеек, а затем пользователь прокручивает виртуализированный грид к строкам, которых не было в окне
- **THEN** появившиеся ячейки не флэшат

### Requirement: Повторное изменение перезапускает флэш

Изменение значения или вызов `flashCells` во время флэша ячейки MUST перезапускать его с начала
фазы заливки.

#### Scenario: Изменение во время затухания

- **WHEN** ячейка с `flashDuration: 500` и `fadeDuration: 1000` флэшит, и через 800 мс её значение снова меняется
- **THEN** ячейка снова в фазе заливки и завершает флэш через 1500 мс после второго изменения

### Requirement: Системные ячейки не флэшат

Ячейки системных колонок (перетаскивание строк, выбор, раскрытие, группировка, действия) и
placeholder-ячейки строк группировки MUST NOT флэшить ни автоматически, ни через `flashCells`.
Агрегированные значения строк группировки MUST флэшить по тем же правилам, что обычные ячейки.

#### Scenario: Флэш всех ячеек строки

- **WHEN** в гриде с выбором строк приложение вызывает `table.flashCells({ rowIds: ['r1'] })`
- **THEN** ячейка выбора строки `r1` не флэшит

#### Scenario: Агрегат группы изменился

- **WHEN** в сгруппированном гриде с `flashing: true` меняется значение строки, и сумма по её группе меняется
- **THEN** ячейка агрегата на строке группы флэшит

### Requirement: Открытый редактор не флэшит

Ячейка с открытым редактором MUST NOT флэшить. Если значение изменилось, пока редактор открыт, а
правку отменили, ячейка MUST NOT флэшить после закрытия редактора. Изменение, пришедшее после
успешного сохранения правки, MUST флэшить как любое другое.

#### Scenario: Отмена правки после обновления данных

- **WHEN** пользователь редактирует ячейку `price`, новые `data` меняют её значение, и пользователь отменяет правку
- **THEN** ячейка показывает новое значение и не флэшит

#### Scenario: Сохранённая правка

- **WHEN** пользователь сохраняет новое значение ячейки `price`, и приложение передаёт его в `data`
- **THEN** ячейка флэшит

### Requirement: Флэш виден китам через атрибут ячейки

Флэшащая ячейка MUST нести `data-flash="flash"` в фазе заливки и `data-flash="fade"` в фазе
затухания, и CSS-переменную `--dg-flash-fade-duration` с длительностью затухания; вне флэша
атрибута нет. Структурный stylesheet MUST накрывать ячейку с `data-flash` оверлеем, не ломая
закрепление колонок; цвет и затухание оверлея задаёт кит.

#### Scenario: Фазы на DOM

- **WHEN** ячейка с `flashDuration: 500` и `fadeDuration: 1000` флэшит
- **THEN** первые 500 мс на её `td` стоит `data-flash="flash"`, следующие 1000 мс — `data-flash="fade"`, затем атрибута нет

#### Scenario: Закреплённая ячейка

- **WHEN** флэшит ячейка закреплённой колонки
- **THEN** она остаётся закреплённой и непрозрачной для прокручиваемого под ней содержимого

### Requirement: Флэш не является состоянием таблицы

Флэш MUST NOT попадать в состояние таблицы: ни вызов `flashCells`, ни фазы флэша не вызывают
`onStateChange`, не меняют `table.store.state` и не попадают в persist-утилиты.

#### Scenario: Вызов flashCells

- **WHEN** приложение подписано на `onStateChange` и вызывает `table.flashCells()`
- **THEN** `onStateChange` не вызывается

### Requirement: Опция без фичи предупреждает

Если `flashing` задан на гриде или колонке, а фича флэша не зарегистрирована, грид в development
MUST выводить предупреждение и не флэшить.

#### Scenario: Фича не зарегистрирована

- **WHEN** грид в development объявлен с `flashing: true` и набором `features` без фичи флэша
- **THEN** грид выводит одно предупреждение, и ячейки не флэшат
