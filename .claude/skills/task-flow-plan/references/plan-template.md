# Шаблон комментария-плана (RU)

Утверждённый план постится в issue **на русском** этим шаблоном. Заполняй только то,
что реально относится к задаче — лишние секции убирай (YAGNI). Пиши по делу, без воды.

```markdown
## План выполнения

**Задача:** <одно-два предложения — что делаем и зачем>

### Шаги
1. <шаг>
2. <шаг>
3. <шаг>

### Затрагиваемые пакеты / файлы
- `packages/...` — <что меняем>
- `apps/docs/...` — <что меняем>

### Проверка
- [ ] lint + typecheck + test затронутого пакета
- [ ] code-review (сабагент)
- [ ] визуальное ревью (playwright, desktop) — <если визуальная задача; иначе «не требуется»>

### Доставка
Ветка `issue-<N>-<slug>` → PR с `Closes #<N>`.

> План согласован в чате перед публикацией. Реализация — после перевода задачи в Ready.
```

## Заметки

- Заголовки/текст — русские, как и сами issue.
- Не выдумывай шаги «на будущее» — только то, что нужно для этой задачи.
- Если задача чисто не-визуальная (типы, конфиг, рефактор без UI) — строку про
  визуальное ревью помечай «не требуется».
