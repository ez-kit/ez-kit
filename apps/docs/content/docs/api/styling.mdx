---
title: '@ez-kit/styling'
description: Styling utilities for class composition and normalized CSS custom properties.
---

## Exports

- `cx(...values)`
- `cssVar(name, value)`

## Example

```ts
import { cssVar, cx } from '@ez-kit/styling'

const className = cx('btn', { 'btn-active': true })
const style = cssVar('brand-color', 'tomato')
```
