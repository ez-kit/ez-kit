# `@ez-kit/ui`

## Exports

- `clamp(value, min, max)`
- `toPx(value)`
- `isClientEnvironment()`

## Example

```ts
import { clamp, toPx } from '@ez-kit/ui'

const width = toPx(clamp(480, 320, 1280))
```
