## localStorage for preferences

```ts
import { localStorageAdapter } from '@ez-kit/zu-store/persist/storage'

const sources = { browser: localStorageAdapter({ storageKey: 'my-preferences' }) }
```

Pass `sources` to `<StoreProvider persist={sources} defaultSource='browser'>` as in the
[first example](./index.mdx). Reload the page to restore the same preferences on this browser.

## sessionStorage for a tab session

```ts
import { sessionStorageAdapter } from '@ez-kit/zu-store/persist/storage'

const sources = { browser: sessionStorageAdapter({ storageKey: 'my-draft' }) }
```

The store and its field declarations stay the same. Change either setting, then reload this
tab. Session storage is scoped to the tab session, so it is a good fit for a short form draft.

## URL for state you can share

Use URL for searchable filters, sort order and pagination. The [URL quick start](./quick-start-url)
shows the router adapter, query keys and a working search example.

## IndexedDB for async browser storage

```ts
import { indexedDbAdapter } from '@ez-kit/zu-store/persist/storage'

const sources = { browser: indexedDbAdapter({ dbName: 'my-app' }) }
```

Again, the store uses the same two fields. Change a setting, wait for it to save, then reload.
Restoration starts automatically after mount. Use `usePersistStatus(store, 'browser')` to show
whether the read is pending, ready, timed out or failed.
