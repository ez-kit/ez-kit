# TypeScript & build setup

This page covers the toolchain configuration the [decorator API](./valtio-kit/search-params/decorators) needs. For the introductory version, see [Getting Started](./valtio-kit/getting-started). **Only `@searchParam` needs this** — the [accessor API](./valtio-kit/search-params/fields) and plain `createContextStore` need no special setup.

`@searchParam` uses **Stage 3 (standard) decorators** with `Symbol.metadata`. No `reflect-metadata`, no `emitDecoratorMetadata`.

```jsonc
// tsconfig.json — TypeScript ≥ 5.2
{
	"compilerOptions": {
		"target": "ES2022"
		// Do NOT set experimentalDecorators — Stage 3 is the default and what this package needs.
		// "experimentalDecorators": false
	}
}
```

## Requirements

- **`experimentalDecorators` must be off** (or absent). The legacy decorator mode is incompatible.
- **`Symbol.metadata`** is read at bind time. Modern bundlers (esbuild/Vite, swc, Babel `@babel/plugin-proposal-decorators` v2023-05, tsc) emit it. On runtimes without it, add a one-line polyfill at your entry:

```ts
;(Symbol as { metadata?: symbol }).metadata ??= Symbol.for('Symbol.metadata')
```

- **Decorators are applied in your code**, so your bundler must transpile them. If you can't enable Stage 3 decorators, use the [accessor API](./valtio-kit/search-params/fields) instead — it needs **no transpilation** and is fully equivalent.

## Toolchain notes

| Toolchain | Status |
| --- | --- |
| TypeScript ≥ 5.2 (`tsc`) | Emits Stage 3 decorators + `Symbol.metadata`. |
| esbuild / Vite | Supported (esbuild ≥ 0.21). |
| SWC (Next.js, etc.) | Supported with `target` ES2022 and no `experimentalDecorators`. |
| Babel | `@babel/plugin-proposal-decorators` version `2023-05`. |

<Callout type="warn">
	If you set `experimentalDecorators: true` anywhere in your config chain, `@searchParam` will not bind correctly.
	Remove it, or switch that store to the accessor API.
</Callout>

## Prefer no build step?

The [accessor API](./valtio-kit/search-params/fields) declares the same fields with `field()` selectors and needs no decorator transpilation — it's the drop-in alternative when Stage 3 decorators aren't available in your toolchain.
