# Migrating from `createPersistStore`

Persistence is now a **plugin** on the base store, not a bespoke store factory. The dedicated `createPersistStore` and `createPersistFields` factories are removed; instead you pass the [`persist()`](./valtio-kit/persist) plugin to the plugin-capable `createStore` (or to a cached [`createCachedStore`](./valtio-kit/cache)).

**Everything else is unchanged** — `@persistUrl()` / `@persistLocalStorage()` / `@persistField()` decorators, the accessor builder (`urlField()`, `localStorageField()`, …), all codecs, every adapter (`localStorageAdapter`, `indexedDbAdapter`, the URL adapters), `useHydrated`, and the `$url` / `$persist` handles. Only the store factory and the top-level provider move.

## `createPersistStore` → `createStore` + `persist()`

Decorator stores discovered fields automatically — `persist()` with no `fields` does the same:

```tsx
// Before
import { createPersistStore } from '@ez-kit/valtio-kit/persist'

const filtersStore = createPersistStore(() => proxy(new Filters()))
```

```tsx
// After
import { createStore } from '@ez-kit/valtio-kit'
import { persist } from '@ez-kit/valtio-kit/persist'

const filtersStore = createStore(() => proxy(new Filters()), { plugins: [persist()] })
```

The returned `{ Provider, useStore, useSnapshot, Item }` shape is identical, so component code that reads `useSnapshot()` and mutates `useStore()` needs no change.

## `createPersistFields` → `persist({ fields })`

The accessor builder moves verbatim into the plugin's `fields` option:

```tsx
// Before
import { createPersistFields } from '@ez-kit/valtio-kit/persist'

const store = createPersistFields(
	() => proxy({ q: '', page: 1 }),
	(field) => [field((s) => s.q, urlField()), field((s) => s.page, urlField())],
)
```

```tsx
// After
import { createStore } from '@ez-kit/valtio-kit'
import { persist } from '@ez-kit/valtio-kit/persist'

const store = createStore(() => proxy({ q: '', page: 1 }), {
	plugins: [persist({ fields: (field) => [field((s) => s.q, urlField()), field((s) => s.page, urlField())] })],
})
```

## `useHydrated` is now a standalone hook

The store result no longer exposes a `useHydrated()` method. Import the standalone hook and pass it the raw proxy from `useStore()`:

```tsx
// Before
const hydrated = prefsStore.useHydrated()
```

```tsx
// After
import { useHydrated } from '@ez-kit/valtio-kit/persist'

const store = prefsStore.useStore()
const hydrated = useHydrated(store)
```

## Provider: `StoreProvider` over bare `PersistProvider`

A bare `PersistProvider adapters={[…]}` still works for persist-only apps and is unchanged. When you also use the cache (or want one composition root for both), wrap with `StoreProvider` — it mounts the persist engines **and** the cache in the correct order:

```tsx
// Before — persist only
<PersistProvider adapters={[reactRouterAdapter, localStorageAdapter()]}>{children}</PersistProvider>
```

```tsx
// After — persist (+ optional cache) under one root
import { StoreProvider } from '@ez-kit/valtio-kit'
;<StoreProvider
	persist={[reactRouterAdapter, localStorageAdapter()]}
	cache={cache}
>
	{children}
</StoreProvider>
```

Omit `cache` for a persist-only tree (equivalent to `PersistProvider`), or omit `persist` for cache-only. A store that is both cached and persisted is covered in [Cached stores](./valtio-kit/persist/cache).

## Summary

| Before                                                              | After                                                                                      |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `createPersistStore(factory)`                                       | `createStore(factory, { plugins: [persist()] })`                                           |
| `createPersistFields(factory, fields)`                              | `createStore(factory, { plugins: [persist({ fields })] })`                                 |
| `store.useHydrated()`                                               | `useHydrated(store.useStore())`                                                            |
| `<PersistProvider adapters={[…]}>`                                  | `<StoreProvider persist={[…]} cache={cache}>` (or keep `PersistProvider` for persist-only) |
| decorators, accessor builder, codecs, adapters, `$url` / `$persist` | unchanged                                                                                  |
