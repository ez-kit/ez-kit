# Use with AI

Every page of this site is available as plain Markdown, so an LLM or a coding agent can read the
documentation directly instead of scraping rendered HTML.

## Endpoints

| URL                                | What it is                                                                                | Use it when                                                  |
| ---------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| [`/llms.txt`](/llms.txt)           | Index of every page — title, link and one-line description, grouped by section. A few KB. | You want the agent to pick the relevant pages itself.        |
| [`/llms-full.txt`](/llms-full.txt) | The entire documentation as one Markdown file — every package, a few hundred KB.          | You have a large context window and want everything at once. |
| `/llms.mdx/docs/<slug>`            | A single page as raw Markdown.                                                            | You already know which page you need.                        |

The per-page route mirrors the docs URL: the page at `/docs/data-grid/getting-started` is served as
Markdown at [`/llms.mdx/docs/data-grid/getting-started`](/llms.mdx/docs/data-grid/getting-started).

## From the page you are reading

Every docs page carries two controls under its title:

- **Copy Markdown** — puts the Markdown source of that page on your clipboard, ready to paste into a chat.
- **View options** — opens the same Markdown in a new tab, or the source file on GitHub.

## Examples

Point an agent at the index and let it fetch what it needs:

```text
Read https://ez-kit.dev/llms.txt, then read the pages you need from it,
and add a sortable @ez-kit/data-grid-shadcn table to my app.
```

Pull a single page from the terminal:

```bash
curl https://ez-kit.dev/llms.mdx/docs/va-store/persist
```

Or hand over the whole corpus:

```bash
curl -O https://ez-kit.dev/llms-full.txt
```

<Callout title='Docs describe the published packages'>

	differences.
</Callout>
