# Selection

Render a checkbox column to let users select rows, then act on them with a bulk-action bar.

## Usage

Click checkboxes to select rows; the header checkbox toggles every row on the current page.

<DataGridDocsExample exampleId='base-selection' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	selection
/>
```

## Options

| Option               | Type                              | Description                                                                          |
| -------------------- | --------------------------------- | ------------------------------------------------------------------------------------ |
| `selection`          | `boolean \| SelectionConfig`      | Master switch. `true` enables multi-select with no info panel. Default `false`.      |
| `selection.multiple` | `boolean`                         | Default `true`. Set `false` to allow only one selected row.                          |
| `selection.onChange` | `(rowIds: string[]) => void`      | Subscribe. Receives selected row ids, **not** `RowSelectionState`.                   |
| `selection.panel`    | `boolean \| SelectionPanelConfig` | React-only. Selection info bar; shown when ≥1 row selected.                          |
| `state.rowSelection` | `RowSelectionState`               | Controlled state — see [Controlled state](/docs/data-grid/controlled-state).         |
| `getRowId`           | `(row) => string`                 | REQUIRED if you want stable selection across data refreshes; default uses row index. |
