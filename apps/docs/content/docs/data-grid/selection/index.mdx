# Selection

Render a checkbox column to let users select rows, then act on them with a bulk-action bar.

## Usage

Click checkboxes to select rows; the header checkbox toggles every row on the current page.

<DataGridDocsExample exampleId='base-selection' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	selection
/>
```

## Options

| Option               | Type                                                          | Description                                                                                                                                                                           |
| -------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `selection`          | `boolean \| SelectionConfig`                                  | Master switch. `true` enables multi-select with the info bar. Default `false`.                                                                                                        |
| `selection.multi`    | `boolean`                                                     | Default `true`. Set `false` to allow only one selected row: selecting a row clears the previous one, and the header shows no select-all checkbox.                                     |
| `selection.onChange` | `(rowSelection: RowSelectionState, rowIds: string[]) => void` | Subscribe. The slice first, like every other feature; the selected ids follow as a convenience.                                                                                       |
| `selection.bar`      | `boolean \| 'floating' \| 'inline' \| SelectionBarConfig`     | React-only. Presentational config for the selection info bar; shown when ≥1 row is selected. The scalar is the render mode. Its Delete button is `deleting.bulk`.                     |
| `state.rowSelection` | `RowSelectionState`                                           | Controlled state — see [Controlled state](./data-grid/controlled-state).                                                                                                              |
| `getRowId`           | `(row) => string`                                             | Only needed when the primary key is not `row.id` — the default already keys on it (falling back to the row index when it is missing), so selection survives a refetch out of the box. |
| `selection.enabled`  | `boolean`                                                     | Explicit off-switch for a config that came from a defaults layer — the settings survive, the feature does not. Default `true`.                                                        |
| `selection.column`   | `SystemColumnDef`                                             | The checkbox column itself — its width, pinning, alignment. See [Row actions](./data-grid/row-actions#the-column-itself) for the shared shape. Pinned `'left'` at `44px` by default.  |
