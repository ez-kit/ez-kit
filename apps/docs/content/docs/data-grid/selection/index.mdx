# Selection

Render a checkbox column to let users select rows, then act on them with a bulk-action bar.

## Usage

Click checkboxes to select rows; the header checkbox toggles every row on the current page.

<DataGridDocsExample exampleId='base-selection' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	enableRowSelection
	enableMultiRowSelection
/>
```

## Options

| Option                    | Type                          | Description                                                                          |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------------------ |
| `enableRowSelection`      | `boolean \| (row) => boolean` | Master switch. Pass a fn to enable per-row. Default `false`.                         |
| `enableMultiRowSelection` | `boolean`                     | Default `true`. Set `false` to allow only one selected row.                          |
| `enableSubRowSelection`   | `boolean`                     | Selecting a parent also selects its sub-rows.                                        |
| `state.rowSelection`      | `Record<string, boolean>`     | Controlled selection state.                                                          |
| `onRowSelectionChange`    | `(updater) => void`           | Subscribe.                                                                           |
| `getRowId`                | `(row) => string`             | REQUIRED if you want stable selection across data refreshes; default uses row index. |
