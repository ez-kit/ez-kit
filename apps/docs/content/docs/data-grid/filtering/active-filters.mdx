---
title: Active Filters
description: The two surfaces that show what is currently filtered — a strip of removable chips and the Clear-all button — auto-mounted or placed by hand.
---

Whatever [variant](/docs/data-grid/filtering/variants) the filter controls use, the grid can show
what is filtered **right now**, apart from the controls themselves: a strip of removable chips, one
per active filter, and a button that clears them all.

Both are variant-independent — the strip reads the filter state, not the header — so they are as
useful beside inline inputs as beside a filter panel. The examples below use the
[popover](/docs/data-grid/filtering/variants) variant, where they earn their space: the controls
sit behind header icons, so the strip is the only place the applied filters are readable. Under the
inline variant each chip merely repeats the input right below it.

## Auto-mounted

`filtering: { chips: true, toolbar: true }` is the whole opt-in. A chip appears per active filter,
and the Clear-all button mounts into the toolbar once at least one filter is set.

<DataGridDocsExample exampleId='filter-chips-auto' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	filtering={{ variant: 'popover', chips: true, toolbar: true }}
	globalFiltering
/>
```

The global search term gets a chip of its own, beside the column ones — the strip lists everything
narrowing the table, not just the column filters.

The strip renders above the table by default; `chips: 'below'` puts it under. The scalar **is** the
position — the object form exists for nothing else today.

<DataGridDocsExample exampleId='filter-chips-below' />

The two flags are independent. `filtering: { chips: true }` alone mounts the strip and nothing
else: each chip still removes its own filter, there is simply no button that clears them all — and
with no other feature asking for the toolbar, the toolbar row itself does not render.

<DataGridDocsExample exampleId='filter-chips-only' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	filtering={{ variant: 'popover', chips: true }}
/>
```

Pass `toolbar: { alwaysShow: true }` to keep the Clear-all button mounted, disabled, even with no
active filter — worth it when its appearing and disappearing makes the toolbar jump.

<DataGridDocsExample exampleId='filter-chips-always' />

## Placed by hand

For full control, drop `<DataGrid.ActiveFiltersBar />` and `<DataGrid.ClearFiltersButton />` wherever
the layout calls for them. Children replace the default layout, so mount the rest of the grid too.

<DataGridDocsExample exampleId='filter-chips-custom' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	filtering={{ variant: 'popover' }}
	globalFiltering
>
	<DataGrid.Toolbar>
		<DataGrid.GlobalFilterInput />
		<DataGrid.ClearFiltersButton>Reset</DataGrid.ClearFiltersButton>
	</DataGrid.Toolbar>
	<DataGrid.ActiveFiltersBar />
	<DataGrid.Table />
	<DataGrid.Pagination />
</DataGrid>
```

`ClearFiltersButton` takes its own children as the label, and its own `alwaysShow` prop overriding
the table config for that one button.

Neither renders while no filter is active — the strip has nothing to list, and the button hides
unless `alwaysShow` — so neither needs a guard of yours around it.

## Options

### `filtering`

| Option    | Type                                | Description                                                                                |
| --------- | ----------------------------------- | ------------------------------------------------------------------------------------------ |
| `chips`   | `boolean \| FilterChipsConfig`      | Auto-mount the strip of removable chips. The scalar `'above'` / `'below'` is its position. |
| `toolbar` | `boolean \| FilteringToolbarConfig` | Auto-mount filtering's toolbar control — the Clear-all button.                             |

### `FilterChipsConfig`

| Option     | Type                 | Description                                                                            |
| ---------- | -------------------- | -------------------------------------------------------------------------------------- |
| `position` | `'above' \| 'below'` | Where to render the auto-mounted chips strip relative to the table. Default `'above'`. |

### `FilteringToolbarConfig`

| Option       | Type      | Description                                                                          |
| ------------ | --------- | ------------------------------------------------------------------------------------ |
| `alwaysShow` | `boolean` | Render the Clear-all button (disabled) even with no active filters. Default `false`. |
