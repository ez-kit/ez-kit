# Multi-value Filter

For columns with a bounded set of values (status, category, tag), let users pick multiple values at once.

## Usage

Multi-value filters let users pick any combination of values from a `select` or `badge` column to narrow the table. The default `in` operator keeps every row whose value matches one of the selected options.

<DataGridDocsExample exampleId='filter-multi-value-in' />

With `filtering: { faceted: true }`, each option also shows how many rows would remain if it were selected — useful for analytics-shaped grids.

<DataGridDocsExample exampleId='filter-multi-value-faceted' />

Flip the default to `notIn` to exclude the selected values instead of including them.

<DataGridDocsExample exampleId='filter-multi-value-not-in' />

```ts
const columns = defineColumns<Order>([
	{
		id: 'status',
		accessorKey: 'status',
		meta: {
			filterVariant: 'multiselect',
			options: [
				{ label: 'Pending', value: 'pending' },
				{ label: 'Shipped', value: 'shipped' },
				{ label: 'Delivered', value: 'delivered' },
				{ label: 'Cancelled', value: 'cancelled' },
			],
		},
	},
])
```

## Faceted counts

When `meta.faceted` is `true`, each option shows the count of rows currently matching it (post-other-filters). Useful for analytics-shaped grids.

## Options

| Option | Type | Description |
| --- | --- | --- |
| `meta.filterVariant` | `'select' \| 'multiselect'` | `'select'` allows one value; `'multiselect'` allows many. |
| `meta.options` | `Array<{ label, value }>` | Required. |
| `meta.faceted` | `boolean` | Default `false`. When `true`, options show live counts. |
