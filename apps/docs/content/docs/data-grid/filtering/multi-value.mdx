# Multi-value Filter

For columns with a bounded set of values (status, category, tag), let users pick multiple values at once.

## Usage

Multi-value filters are available on `select` and `badge` cell types. The default `in` operator keeps every row whose value matches one of the selected options.

<DataGridDocsExample exampleId='filter-multi-value-in' />

With `filtering: { faceted: true }`, each option also shows how many rows would remain if it were selected — useful for analytics-shaped grids.

<DataGridDocsExample exampleId='filter-multi-value-faceted' />

Set the column's `filtering.defaultOperator` to `'notIn'` to exclude the selected values instead of including them.

<DataGridDocsExample exampleId='filter-multi-value-not-in' />

```ts
const columns = createColumns<Order>([
	{
		accessorKey: 'status',
		header: 'Status',
		cell: {
			type: 'select',
			config: {
				items: [
					{ value: 'pending', label: 'Pending' },
					{ value: 'shipped', label: 'Shipped' },
					{ value: 'delivered', label: 'Delivered' },
					{ value: 'cancelled', label: 'Cancelled' },
				],
			},
		},
		filtering: { operators: true },
	},
])
```

## Faceted counts

When `filtering.faceted` is `true` on the table (or the column overrides it to `true`), each option shows the count of rows currently matching it (post-other-filters). Useful for analytics-shaped grids.

## Options

### `cell` (select / badge)

| Option         | Type                                              | Description                                                                   |
| -------------- | ------------------------------------------------- | ----------------------------------------------------------------------------- |
| `type`         | `'select' \| 'badge'`                             | `'select'` renders plain items; `'badge'` renders colored badges.             |
| `config.items` | `Array<{ value, label }>` (badge adds `variant?`) | The option list used both for cell display and for the `in` / `notIn` filter. |

### Per-column `filtering`

| Option            | Type                                        | Description                                                                                        |
| ----------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `operators`       | `boolean \| ColumnOperatorsConfig`          | `true` enables the default `select`/`badge` operator set (`in`, `notIn`, `isEmpty`, `isNotEmpty`). |
| `defaultOperator` | `string`                                    | `'in'` (default) keeps selected values; `'notIn'` excludes them.                                   |
| `items`           | `FilterItem[]` — `{ value, label, count? }` | Explicit value list — overrides `cell.config.items` and faceted values for the filter input.       |
| `faceted`         | `boolean`                                   | Per-column override for the table-level `filtering.faceted` flag.                                  |
