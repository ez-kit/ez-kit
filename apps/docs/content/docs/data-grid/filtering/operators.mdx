# Filter Operators

Each column can expose a list of operators the user picks from when filtering — `contains`, `equals`, `startsWith`, `gt`, `lt`, `between`, and more. Operators are configured per column via `filtering.operators`, and the default set is picked from the column's `cell.type`.

## Usage

```ts
const columns = defineColumns<Employee>([
	{
		accessorKey: 'name',
		header: 'Name',
		filtering: { operators: { items: ['contains', 'equals', 'startsWith'] }, defaultOperator: 'contains' },
	},
])
```

### Text operators

Enable the full text operator set with `filtering: { operators: true }`, or pass an explicit `items` list to restrict it — here **Department** offers only `contains`, `equals`, `isEmpty`, and `isNotEmpty`.

### Number operators

Numeric columns (`cell: { type: 'number' }`) expose comparison operators (`eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `between`). Use `defaultOperator` to pick the one selected first — **Salary** defaults to `gte`.

### Between — inputs

The `between` operator renders two bound inputs when `betweenOperator.variant` is `'inputs'`, matching an inclusive numeric range.

<DataGridDocsExample exampleId='filter-operators-between-inputs' />

### Between — slider

Switch `betweenOperator.variant` to `'slider'` and provide `min`/`max` for a draggable range control instead of typed bounds.

<DataGridDocsExample exampleId='filter-operators-between-slider' />

### Date operators

Date columns (`cell: { type: 'date' }`) get date-aware operators (`eq`, `before`, `onOrBefore`, `after`, `onOrAfter`, `between`) with a calendar picker. Enable them with `filtering: { operators: true }`.

<DataGridDocsExample exampleId='filter-operators-date' />

### Date between

Combine the date operators with `between` (`betweenOperator.variant: 'inputs'`) to filter rows falling inside a start–end date range.

## Built-in operators

| Operator                                               | Cell type           | Behavior                                                                         |
| ------------------------------------------------------ | ------------------- | -------------------------------------------------------------------------------- |
| `contains`                                             | text                | substring match (case-insensitive)                                               |
| `equals`                                               | text                | case-insensitive equality                                                        |
| `startsWith` / `endsWith`                              | text                | prefix / suffix (case-insensitive)                                               |
| `isEmpty` / `isNotEmpty`                               | text, select, badge | null / undefined / empty string — renders no value input                         |
| `eq` / `neq`                                           | number              | equals / not equals                                                              |
| `gt` / `gte` / `lt` / `lte`                            | number              | comparison                                                                       |
| `between`                                              | number, date        | inclusive range                                                                  |
| `eq` / `before` / `onOrBefore` / `after` / `onOrAfter` | date                | date comparison, string-ordered                                                  |
| `in`                                                   | select, badge       | row value is one of a set (see [Multi-value](./data-grid/filtering/multi-value)) |
| `notIn`                                                | select, badge       | inverse of `in`                                                                  |

There is no `notEquals` operator — use `neq` on `number` columns; text columns have no inequality operator.

## Custom operators

```ts
filtering: {
	operators: {
		items: ['contains', { id: 'fuzzy', label: 'Fuzzy match', filterFn: fuzzyMatch }],
	},
}
```

## `ColumnOperatorsConfig`

| Option            | Type                              | Description                                                                                                                           |
| ----------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `items`           | `(string \| FilterOperatorDef)[]` | Operator ids referencing the registry, or inline operator definitions. Omit to use every default operator for the column's cell type. |
| `betweenOperator` | `BetweenOperatorConfig`           | UI configuration for the `between` operator — see below.                                                                              |

### `BetweenOperatorConfig`

| Option    | Type                                 | Description                                                                                                                   |
| --------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `variant` | `'inputs' \| 'slider' \| 'calendar'` | Control shape. Default `'inputs'`.                                                                                            |
| `min`     | `number`                             | Minimum value for the `'slider'` variant.                                                                                     |
| `max`     | `number`                             | Maximum value for the `'slider'` variant.                                                                                     |
| `presets` | `boolean \| DateRangePreset[]`       | Show preset chips above the input(s). Only meaningful on `date` columns — see [Date range](./data-grid/filtering/date-range). |

### `FilterOperatorDef`

| Field           | Type                                          | Description                                                                |
| --------------- | --------------------------------------------- | -------------------------------------------------------------------------- |
| `id`            | `string`                                      | Operator id, referenced from `items`.                                      |
| `label`         | `string`                                      | Label shown in the operator selector.                                      |
| `requiresInput` | `boolean`                                     | When `false`, no value input is rendered (e.g. `isEmpty`). Default `true`. |
| `filterFn`      | `(rowValue: unknown, filterValue) => boolean` | Matching predicate.                                                        |
