# Filter Operators

Each column can expose a list of operators the user picks from when filtering — `=`, `≠`, `contains`, `starts with`, `>`, `<`, `between`, and more. Operators are configured per column via `meta`.

## Usage

```ts
const columns = defineColumns<User>([
	{
		id: 'name',
		accessorKey: 'name',
		meta: {
			filterVariant: 'text',
			operators: ['contains', 'equals', 'startsWith'],
			defaultOperator: 'contains',
		},
	},
])
```

### Text operators

Enable the full text operator set with `filtering: { operators: true }`, or pass an explicit `items` list to restrict it — here **Department** offers only `contains`, `equals`, `isEmpty`, and `isNotEmpty`.

### Number operators

Numeric columns expose comparison operators (`=`, `≠`, `>`, `≥`, `<`, `≤`). Use `defaultOperator` to pick the one selected first — **Salary** defaults to `gte`.

### Between — inputs

The `between` operator renders two bound inputs when `betweenOperator.variant` is `'inputs'`, matching an inclusive numeric range.

<DataGridDocsExample exampleId='filter-operators-between-inputs' />

### Between — slider

Switch `betweenOperator.variant` to `'slider'` and provide `min`/`max` for a draggable range control instead of typed bounds.

<DataGridDocsExample exampleId='filter-operators-between-slider' />

### Date operators

Date columns get date-aware operators (`before`, `after`, `between`, …) with a calendar picker. Enable them with `filtering: { operators: true }`.

### Date between

Combine the date operators with `between` (`betweenOperator.variant: 'inputs'`) to filter rows falling inside a start–end date range.

## Built-in operators

| Operator | Applies to | Behavior |
| --- | --- | --- |
| `equals` | any | strict equality |
| `notEquals` | any | strict inequality |
| `contains` | string | substring match (case-insensitive by default) |
| `startsWith` / `endsWith` | string | prefix / suffix |
| `gt` / `gte` / `lt` / `lte` | number, date | comparison |
| `between` | number, date | inclusive range |
| `in` | any | row value is one of a set (see [Multi-value](./data-grid/filtering/multi-value)) |
| `notIn` | any | inverse of `in` |
| `isEmpty` / `isNotEmpty` | any | null / undefined / empty string |

## Custom operators

```ts
meta: {
	operators: ['contains', { id: 'fuzzy', label: 'Fuzzy match', fn: fuzzyMatch }],
}
```
