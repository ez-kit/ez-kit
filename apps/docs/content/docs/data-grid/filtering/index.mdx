title: Filtering

Filtering narrows the visible rows by matching column values against user input. Each column can have its own filter type and operator.

## Usage

`filtering` on the grid opts every column in, with the control rendered inline in the header — the
default of three presentations, all of which are on [Variants](/docs/data-grid/filtering/variants).

<DataGridDocsExample exampleId='base-filtering' />

Opt columns into richer comparisons with `filtering: { operators }` — text operators like _contains_
/ _equals_ / _is empty_, a `between` slider for numbers, and date-aware operators. `initialState`
seeds the filters the grid opens with:

```tsx
<DataGrid
	data={data}
	columns={columns}
	filtering
	initialState={{
		columnFilters: [{ id: 'status', value: 'active' }],
	}}
/>
```

## Options

### `filtering`

| Option      | Type                                                 | Description                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`   | `'inline' \| 'popover' \| 'panel'`                   | Where every column's filter control renders — see [Variants](/docs/data-grid/filtering/variants). Default `'inline'`.                                                                                                                                                                                                                                               |
| `manual`    | `boolean`                                            | Disable client-side column filtering (and global filter). The grid calls `onChange` instead.                                                                                                                                                                                                                                                                        |
| `operators` | `boolean \| TableOperatorsConfig`                    | Operator selectors for the whole table: `true` gives every filterable column the default operators for its `cell.type`, `false` gives none of them one, and `{ items }` registers custom operators columns reference by id (and switches them on like `true`). Omit it to leave the decision to each column — see [Operators](/docs/data-grid/filtering/operators). |
| `faceted`   | `boolean`                                            | Enable faceted row models (unique values + counts) for multi-select filters. Default `false`.                                                                                                                                                                                                                                                                       |
| `debounce`  | `number`                                             | Commit debounce (ms) shared by every text filter input, the global search box included. Default `250`. `0` commits every keystroke.                                                                                                                                                                                                                                 |
| `chips`     | `boolean \| 'above' \| 'below' \| FilterChipsConfig` | Auto-mount a strip of removable chips for active filters. The scalar is the position — `chips: 'below'` — and the object exists for anything more; see [Active filters](/docs/data-grid/filtering/active-filters).                                                                                                                                                  |
| `toolbar`   | `boolean \| FilteringToolbarConfig`                  | Auto-mount filtering's toolbar control — the Clear-all button — see [Active filters](/docs/data-grid/filtering/active-filters).                                                                                                                                                                                                                                     |
| `onChange`  | `(columnFilters: ColumnFiltersState) => void`        | Called when any column filter changes.                                                                                                                                                                                                                                                                                                                              |
| `enabled`   | `boolean`                                            | Explicit off-switch for a config that came from a defaults layer — the settings survive, the feature does not. Default `true`.                                                                                                                                                                                                                                      |

### Per-column `filtering`

| Option            | Type                                        | Description                                                                                                                                                                                               |
| ----------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `false`           | —                                           | Disable filtering for this column.                                                                                                                                                                        |
| `component`       | `(props: InputComponentProps) => ReactNode` | Custom filter input for this column. `props.config` is the column's own `cell.config` — annotate the component (`InputComponentProps<SelectCellConfig>`) to read it without a cast.                       |
| `operators`       | `boolean \| ColumnOperatorsConfig`          | Operator configuration. `true` = default operators for the column's cell type, `false` = none even under a table-wide `filtering.operators: true` — see [Operators](/docs/data-grid/filtering/operators). |
| `defaultOperator` | `FilterOperatorId`                          | Which operator the filter opens with. Must be one of the operators the column offers — `createTable` warns in development when it is not.                                                                 |
| `items`           | `FilterItem[]`                              | Explicit value list for multi-value (`in` / `notIn`) filters — see [Multi-value](/docs/data-grid/filtering/multi-value).                                                                                  |
| `faceted`         | `boolean`                                   | Per-column override for the table-level `filtering.faceted` flag.                                                                                                                                         |
| `debounce`        | `number`                                    | Commit debounce (ms) for this column's text filter, overriding the table-level `filtering.debounce`. Discrete controls commit instantly and ignore it.                                                    |

Filterable columns pick their default operator set from `cell.type` — every built-in type has one — see [Operators](/docs/data-grid/filtering/operators).
