# Filtering

Filtering narrows the visible rows by matching column values against user input. Each column can have its own filter type and operator.

## Usage

Base behavior — per-column filter inputs:

<DataGridDocsExample exampleId='base-filtering' />

A filter icon appears in each column header. Click it to open a popover with the filter input; the icon turns the primary colour while a filter is active.

<DataGridDocsExample exampleId='filter-popover-basic' />

Opt columns into richer comparisons with `filtering: { operators }` — text operators like _contains_ / _equals_ / _is empty_, a `between` slider for numbers, and date-aware operators. The popover then renders an operator selector above the input.

<DataGridDocsExample exampleId='filter-popover-operators' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	filtering
	initialState={{
		columnFilters: [{ id: 'status', value: 'active' }],
	}}
/>
```

## Options

### `filtering`

| Option      | Type                                          | Description                                                                                                                          |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `variant`   | `'inline' \| 'popover' \| 'panel'`            | Display variant for column filter controls. Default `'inline'`.                                                                      |
| `manual`    | `boolean`                                     | Disable client-side column filtering (and global filter). The grid calls `onChange` instead.                                         |
| `operators` | `FilterOperatorDef[]`                         | Table-level custom operators (or built-in overrides), referenced by column items — see [Operators](./data-grid/filtering/operators). |
| `faceted`   | `boolean`                                     | Enable faceted row models (unique values + counts) for multi-select filters. Default `false`.                                        |
| `debounce`  | `number`                                      | Commit debounce (ms) shared by every text filter input, the global search box included. Default `250`. `0` commits every keystroke.  |
| `chips`     | `boolean \| FilterChipsConfig`                | Auto-mount a strip of removable chips for active filters — see [Filter panel](./data-grid/filtering/panel).                          |
| `toolbar`   | `boolean \| FilteringToolbarConfig`           | Auto-mount filtering's toolbar control — the Clear-all button — see [Filter panel](./data-grid/filtering/panel).                     |
| `onChange`  | `(columnFilters: ColumnFiltersState) => void` | Called when any column filter changes.                                                                                               |

### Per-column `filtering`

| Option            | Type                                      | Description                                                                                                                       |
| ----------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `false`           | —                                         | Disable filtering for this column.                                                                                                |
| `component`       | `(props: InputComponentProps) => unknown` | Custom filter input component for this column.                                                                                    |
| `operators`       | `boolean \| ColumnOperatorsConfig`        | Operator configuration. `true` = default operators for the column's cell type — see [Operators](./data-grid/filtering/operators). |
| `defaultOperator` | `string`                                  | Override the default selected operator for this column.                                                                           |
| `options`         | `Array<{ label, value, count? }>`         | Explicit option list for multi-value (`in` / `notIn`) filters — see [Multi-value](./data-grid/filtering/multi-value).             |
| `faceted`         | `boolean`                                 | Per-column override for the table-level `filtering.faceted` flag.                                                                 |

Filterable columns pick their default operator set from `cell.type` (`'text'`, `'number'`, `'date'`, `'select'`, `'badge'`) — see [Operators](./data-grid/filtering/operators).
