# Filtering

Filtering narrows the visible rows by matching column values against user input. Each column can have its own filter type and operator.

## Usage

Base behavior — per-column filter inputs:

<DataGridDocsExample exampleId='base-filtering' />

A filter icon appears in each column header. Click it to open a popover with the filter input; the icon turns the primary colour while a filter is active.

<DataGridDocsExample exampleId='filter-popover-basic' />

Opt columns into richer comparisons with `filtering: { operators }` — text operators like _contains_ / _equals_ / _is empty_, a `between` slider for numbers, and date-aware operators. The popover then renders an operator selector above the input.

<DataGridDocsExample exampleId='filter-popover-operators' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	enableColumnFilters
	initialState={{
		columnFilters: [{ id: 'status', value: 'active' }],
	}}
/>
```

## Options

| Option                          | Type                 | Description                                                                                  |
| ------------------------------- | -------------------- | -------------------------------------------------------------------------------------------- |
| `enableColumnFilters`           | `boolean`            | Master switch. Default `true`.                                                               |
| `state.columnFilters`           | `ColumnFiltersState` | Controlled filter state.                                                                     |
| `onColumnFiltersChange`         | `(updater) => void`  | Subscribe to filter changes.                                                                 |
| Per-column `enableColumnFilter` | `boolean`            | Default `true`; turn off for non-filterable columns.                                         |
| Per-column `filterFn`           | name \| custom       | Built-in: `'auto'`, `'includesString'`, `'equals'`, `'arrIncludes'`, `'inNumberRange'`, etc. |
| Per-column `meta.filterVariant` | string               | Hint to the UI which input to render (text, number, select, date).                           |
