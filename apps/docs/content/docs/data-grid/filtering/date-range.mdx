# Date Range Filter

For date columns (`cell: { type: 'date' }`), the `between` operator renders a range picker and supports named presets (today, last 7 days, last 30 days, this month).

## Usage

Built-in presets (Today, Yesterday, Last 7/30 days, This/Last month) sit alongside the two-input range picker via `betweenOperator: { variant: 'inputs', presets: true }`.

<DataGridDocsExample exampleId='filter-date-range-built-in' />

Switch to `variant: 'calendar'` for a true range calendar where the user drags across a month to select both endpoints at once.

<DataGridDocsExample exampleId='filter-date-range-calendar' />

Supply your own `presets` array — quarterly ranges, year-long windows, or anything else that fits your domain — via `betweenOperator: { presets: [...] }`.

<DataGridDocsExample exampleId='filter-date-range-custom' />

```ts
const columns = defineColumns<Release>([
	{
		accessorKey: 'releasedAt',
		header: 'Released',
		cell: { type: 'date' },
		filtering: {
			operators: {
				items: ['eq', 'before', 'after', 'between'],
				betweenOperator: { variant: 'inputs', presets: true },
			},
			defaultOperator: 'between',
		},
	},
])
```

## Options

### `betweenOperator`

| Option    | Type                                 | Description                                                                                                        |
| --------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `variant` | `'inputs' \| 'slider' \| 'calendar'` | Picker shape. `'inputs'` and `'calendar'` apply to date columns; `'slider'` is number-only.                        |
| `presets` | `boolean \| DateRangePreset[]`       | `true` renders the built-in presets; pass an array to use a custom set instead. Only meaningful on `date` columns. |

### `DateRangePreset`

| Field      | Type                                   | Description                                                                      |
| ---------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| `id`       | `string`                               | Preset id.                                                                       |
| `label`    | `string`                               | Label shown in the preset list.                                                  |
| `getRange` | `(now?: Date) => { from?: T; to?: T }` | Returns the `{ from, to }` bounds for the preset, in ISO-8601 date-only strings. |

Built-in preset ids: `'today'`, `'yesterday'`, `'last7'`, `'last30'`, `'thisMonth'`, `'lastMonth'`.

### `cell` (date)

| Option            | Type                         | Description                                                                  |
| ----------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| `config.minValue` | `string` (ISO 8601)          | Hard minimum forwarded to the date picker.                                   |
| `config.maxValue` | `string` (ISO 8601)          | Hard maximum forwarded to the date picker.                                   |
| `config.format`   | `Intl.DateTimeFormatOptions` | Forwarded to `Intl.DateTimeFormat` for cell display — not the filter picker. |

## Notes

The accessor value MUST be a `Date` or an ISO string. If it's something else, supply `accessorFn` to coerce.
