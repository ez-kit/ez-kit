---
title: Date Range Filter
description: Filter rows by a date range — between two dates, before a date, after a date, or by named presets.
---

For date columns (`cell: { type: 'date' }`), the `between` operator renders one range control — a
trigger showing the committed range, opening a two-month range calendar — and supports named presets
(today, last 7 days, last 30 days, this month). The filter is written once both ends are chosen, so a
half-drawn range never reaches the table or a server-driven query.

## Usage

Built-in presets (Today, Yesterday, Last 7/30 days, This/Last month) sit beside the range control via
`betweenOperator: { presets: true }`, behind one menu trigger — the filter also renders inline in the
column header, where a chip per preset wrapped onto several lines and took the height of the whole
header row with it. Picking one fills both ends; the trigger then names the preset the range came
from, and stops naming it as soon as either end is edited by hand.

<DataGridDocsExample exampleId='filter-date-range-built-in' />

Supply your own `presets` array — quarterly ranges, year-long windows, or anything else that fits your domain — via `betweenOperator: { presets: [...] }`.

<DataGridDocsExample exampleId='filter-date-range-custom' />

```ts
const columns = createColumns<Release>([
	{
		accessorKey: 'releasedAt',
		header: 'Released',
		cell: { type: 'date' },
		filtering: {
			operators: {
				items: ['equals', 'lessThan', 'greaterThan', 'between'],
				betweenOperator: { presets: true },
			},
			defaultOperator: 'between',
		},
	},
])
```

## Options

### `betweenOperator`

On a date column the config has exactly one option — how the control looks is the UI kit's business,
not the column's. The number-only half (`slider`, `min`, `max`) is documented under
[Operators](/docs/data-grid/filtering/operators); writing it beside `presets` is a compile error.

| Option    | Type                           | Description                                                                                                        |
| --------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `presets` | `boolean \| DateRangePreset[]` | `true` renders the built-in presets; pass an array to use a custom set instead. Only meaningful on `date` columns. |

### `DateRangePreset`

| Field      | Type                                             | Description                                                                      |
| ---------- | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| `id`       | `string`                                         | Preset id.                                                                       |
| `label`    | `string`                                         | Label shown in the preset list.                                                  |
| `getRange` | `(now?: Date) => { from?: string; to?: string }` | Returns the `{ from, to }` bounds for the preset, in ISO-8601 date-only strings. |

Built-in preset ids: `'today'`, `'yesterday'`, `'last7'`, `'last30'`, `'thisMonth'`, `'lastMonth'`.

### `cell` (date)

| Option          | Type                         | Description                                                                  |
| --------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| `config.min`    | `string` (ISO 8601)          | Hard minimum forwarded to the date picker.                                   |
| `config.max`    | `string` (ISO 8601)          | Hard maximum forwarded to the date picker.                                   |
| `config.format` | `Intl.DateTimeFormatOptions` | Forwarded to `Intl.DateTimeFormat` for cell display — not the filter picker. |

## Notes

The accessor value MUST be a `Date` or an ISO string. If it's something else, supply `accessorFn` to coerce.
