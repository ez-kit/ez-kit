---
title: Date Range Filter
description: Filter rows by a date range — between two dates, before a date, after a date, or by named presets.
---

For date columns (`cell: { type: 'date' }`), the `between` operator renders one range control — a
trigger showing the committed range, opening a two-month range calendar. The filter is written once
both ends are chosen, so a half-drawn range never reaches the table or a server-driven query.

Presets sit beside the control, and not only beside `between`: the menu offers whichever presets the
**current** operator can take. A range fills `between`; a single date fills `equals`, `lessThan`,
`greaterThan` and the rest. The two kinds are separate because a range has no single date to mean —
offering "Last 7 days" to `equals` would have to pick one of its ends and silently turn "the last
week" into "on last Tuesday".

## Usage

`filtering: { presets: true }` offers the built-in set: the ranges (Today, Yesterday, Last 7/30 days,
This/Last month) and the single dates (Today, Yesterday, A week ago, A month ago, Start of month).
They live behind one menu trigger — the filter also renders inline in the column header, where a chip
per preset wrapped onto several lines and took the height of the whole header row with it. Picking
one fills the operator's value; the trigger then names the preset that value came from, and stops
naming it as soon as the value is edited by hand.

<DataGridDocsExample exampleId='filter-date-range-built-in' />

Supply your own `presets` array — quarterly ranges, year-long windows, a single anchor date, or anything else that fits your domain. A preset with `getRange` fills `between`; one with `getDate` fills the operators that take a single date.

<DataGridDocsExample exampleId='filter-date-range-custom' />

```ts
const columns = createColumns<Release>([
	{
		accessorKey: 'releasedAt',
		header: 'Released',
		cell: { type: 'date' },
		filtering: {
			presets: true,
			operators: { items: ['equals', 'lessThan', 'greaterThan', 'between'] },
			defaultOperator: 'between',
		},
	},
])
```

## Options

### `filtering.presets`

| Option    | Type                      | Description                                                                                                                                                     |
| --------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `presets` | `boolean \| DatePreset[]` | `true` offers the built-in presets; pass an array to use a custom set instead. Only meaningful on `date` columns — `mapColumns` warns in development otherwise. |

### `DateRangePreset`

Fills `between`.

| Field      | Type                                             | Description                                                                      |
| ---------- | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| `id`       | `string`                                         | Preset id.                                                                       |
| `label`    | `string`                                         | Label shown in the preset list.                                                  |
| `getRange` | `(now?: Date) => { from?: string; to?: string }` | Returns the `{ from, to }` bounds for the preset, in ISO-8601 date-only strings. |

Built-in range ids: `'today'`, `'yesterday'`, `'last7'`, `'last30'`, `'thisMonth'`, `'lastMonth'`.

### `DateValuePreset`

Fills every date operator that takes a single value.

| Field     | Type                     | Description                                        |
| --------- | ------------------------ | -------------------------------------------------- |
| `id`      | `string`                 | Preset id.                                         |
| `label`   | `string`                 | Label shown in the preset list.                    |
| `getDate` | `(now?: Date) => string` | Returns the date, as an ISO-8601 date-only string. |

Built-in single-date ids: `'today'`, `'yesterday'`, `'weekAgo'`, `'monthAgo'`, `'startOfMonth'`.

### `cell` (date)

| Option          | Type                         | Description                                                                  |
| --------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| `config.min`    | `string` (ISO 8601)          | Hard minimum forwarded to the date picker.                                   |
| `config.max`    | `string` (ISO 8601)          | Hard maximum forwarded to the date picker.                                   |
| `config.format` | `Intl.DateTimeFormatOptions` | Forwarded to `Intl.DateTimeFormat` for cell display — not the filter picker. |

## Notes

The accessor value MUST be a `Date` or an ISO string. If it's something else, supply `accessorFn` to coerce.
