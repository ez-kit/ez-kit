---
title: Global Filtering
description: A single search box that filters rows across every searchable column at once.
---

Sometimes a user just wants one search box, not per-column filters. Global filtering runs a single string match across every column that opts in.

## Usage

A search field sits at the trailing end of the toolbar, or at its leading end — [wherever the layout puts it](#where-the-search-box-sits). Typing into it filters rows across all searchable columns, with a 250ms debounce by default.

<DataGridDocsExample exampleId='global-filtering-basic' />

Global search and per-column filters coexist — enable both `filtering` and `globalFiltering` and they compose.

<DataGridDocsExample exampleId='global-filtering-combined' />

Set `globalFiltering: false` on a column to exclude it from the global match (here the `Internal ID` column is never searched).

<DataGridDocsExample exampleId='global-filtering-excluded' />

Provide your own `fn` to change the match semantics — this one does a starts-with match instead of the default substring search.

<DataGridDocsExample exampleId='global-filtering-custom-fn' />

```tsx
<DataGrid.GlobalFilterInput placeholder='Search…' />
```

```tsx
<DataGrid
	features={features}
	data={data}
	columns={columns}
	globalFiltering
	// Equivalent to the default:
	// globalFiltering={{ fn: 'includesString' }}
/>
```

## Where the search box sits

Wherever the layout writes `<DataGrid.GlobalFilterInput />`. There is no option for it: mounting
the component is what puts a search box in the grid, and which slot it goes in is what says which
end of the toolbar holds it.

`DefaultLayout` — what both UI kits bind — puts it at the toolbar's leading end whenever global
filtering is on, so `globalFiltering` on its own still gives you a search box.

```tsx
<DataGrid.Toolbar
	start={<DataGrid.GlobalFilterInput />}
	end={<DataGrid.VisibilityTrigger />}
/>
```

Search leading, **then** the filter panel, is the order most issue trackers use, and it used to
take two options (`globalFiltering: { toolbar: 'start' }` plus `filtering: { panel: 'toolbar' }`)
to ask for. It is now one slot:

```tsx
<DataGrid.Toolbar
	start={
		<>
			<DataGrid.GlobalFilterInput />
			<DataGrid.FilterPanel />
		</>
	}
/>
```

That whole arrangement ships as the `FilterPanelLayout` preset — see
[Presets](/docs/data-grid/layout/presets#filterpanellayout).

`start` and `end` are logical, not physical: they swap sides under RTL, the same way a column's
`align` does.

## Options

### `globalFiltering`

Global search has no `manual` flag of its own — setting `filtering.manual: true` makes both column filters **and** the global search server-side (see [Server-side Data](/docs/data-grid/state/server-side)).

| Option        | Type                                        | Description                                                                                                                                                                  |
| ------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `placeholder` | `string`                                    | Placeholder for the search input. Default `'Search…'`.                                                                                                                       |
| `debounce`    | `number`                                    | Commit debounce (ms) for the auto-mounted input. Defaults to the shared `filtering.debounce` (250); set it only to time the search box differently. `0` disables debouncing. |
| `fn`          | name \| `(row, columnId, value) => boolean` | Function applied during global search. Default `'includesString'` (case-insensitive substring).                                                                              |
| `fns`         | `Record<string, GlobalFilterFn>`            | Named global filter functions, addressable from `fn` by id.                                                                                                                  |
| `onChange`    | `(globalFilter: unknown) => void`           | Called when the global search value changes.                                                                                                                                 |
| `enabled`     | `boolean`                                   | Explicit off-switch for a config that came from a defaults layer — the settings survive, the feature does not. Default `true`.                                               |

### Per-column `globalFiltering`

| Option  | Type      | Description                                                              |
| ------- | --------- | ------------------------------------------------------------------------ |
| `false` | `boolean` | Exclude this column from global matching. Default `true` (participates). |
