# Sub-content

Click a row to reveal a sub-row of arbitrary content beneath it. Common uses: order line items, JSON detail panels, error stack traces.

## Usage

<DataGridDocsExample exampleId='expanding-sub-content' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	expanding={{
		renderExpanded: ({ row }) => <OrderDetails order={row.original} />,
	}}
/>
```

## Options

| Option                      | Type                            | Description                                                                         |
| --------------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `expanding`                 | `boolean \| ExpandingConfig`    | Master switch. Providing `renderExpanded` also enables it. Default `false`.         |
| `expanding.renderExpanded`  | `ComponentType<{ row, table }>` | Renders the expanded content. Required for sub-content mode.                        |
| `expanding.getRowCanExpand` | `(row) => boolean`              | Per-row expandability. All rows expandable when omitted.                            |
| `state.expanded`            | `ExpandedState`                 | Controlled expand state — see [Controlled state](/docs/data-grid/controlled-state). |
