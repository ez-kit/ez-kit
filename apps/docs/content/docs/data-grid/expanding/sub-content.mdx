# Sub-content

Click a row to reveal a sub-row of arbitrary content beneath it. Common uses: order line items, JSON detail panels, error stack traces.

## Usage

<DataGridDocsExample exampleId='expanding-sub-content' />

```ts
const grid = useDataGrid({
	data,
	columns,
	enableExpanding: true,
	renderSubRow: (row) => <OrderDetails order={row.original} />,
})
```

## Options

| Option | Type | Description |
| --- | --- | --- |
| `enableExpanding` | `boolean` | Master switch. Default `false`. |
| `renderSubRow` | `(row) => ReactNode` | Renders the expanded content. Required when expanding is on. |
| `state.expanded` | `ExpandedState` | Controlled expand state. |
| `onExpandedChange` | `(updater) => void` | Subscribe. |
