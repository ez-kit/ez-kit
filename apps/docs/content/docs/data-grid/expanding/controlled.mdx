# Controlled Expanding

Pass an external `expanded` state into the grid to drive expansion from outside — keyboard shortcuts, URL params, persisted across sessions.

## Usage

<DataGridDocsExample exampleId='expanding-controlled' />

```ts
const [expanded, setExpanded] = useState<ExpandedState>({})

const grid = useDataGrid({
	data,
	columns,
	enableExpanding: true,
	state: { expanded },
	onExpandedChange: setExpanded,
})
```
