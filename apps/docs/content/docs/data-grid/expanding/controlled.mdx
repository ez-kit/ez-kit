# Controlled Expanding

Expanding has no dedicated `expanding.onChange` — pass `expanded` through the general `state` /
`onStateChange` mechanism, the same as every other controllable slot. See
[Controlled state](./data-grid/controlled-state) for the full model.

## Usage

<DataGridDocsExample exampleId='expanding-controlled' />

```tsx
const [tableState, setTableState] = useState<Partial<TableState>>({ expanded: {} })

<DataGrid
	data={data}
	columns={columns}
	expanding={{
		component: ({ row }) => <OrderDetails order={row.original} />,
	}}
	state={tableState}
	onStateChange={(nextState) => {
		setTableState(nextState)
	}}
/>
```
