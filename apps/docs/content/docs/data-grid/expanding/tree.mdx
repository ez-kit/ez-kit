# Tree

When your data is hierarchical (folders, org charts, BOMs), render it as a tree. Parent and child rows share the column set.

## Usage

<DataGridDocsExample exampleId='expanding-tree' />

```tsx
<DataGrid
	data={data} // each row has optional `children: TRow[]`
	columns={columns}
	expanding={{ variant: 'tree' }}
/>
```

## Options

| Option                 | Type                                  | Description                                                  |
| ---------------------- | ------------------------------------- | ------------------------------------------------------------ |
| `expanding.mode`       | `'sub-content' \| 'tree'`             | Mode switch. Default `'sub-content'`.                        |
| `expanding.getSubRows` | `(row, index) => TRow[] \| undefined` | Sub-row extractor. Auto-detects `row.children` when omitted. |
