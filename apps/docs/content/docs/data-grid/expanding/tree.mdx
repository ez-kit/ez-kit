# Tree

When your data is hierarchical (folders, org charts, BOMs), render it as a tree. Parent and child rows share the column set.

## Usage

<DataGridDocsExample exampleId='expanding-tree' />

```ts
const grid = useDataGrid({
	data, // each row has optional `children: TRow[]`
	columns,
	enableExpanding: true,
	getSubRows: (row) => row.children,
})
```

## Options

| Option                  | Type                           | Description                              |
| ----------------------- | ------------------------------ | ---------------------------------------- |
| `getSubRows`            | `(row) => TRow[] \| undefined` | How to find child rows.                  |
| `enableSubRowSelection` | `boolean`                      | Selecting a parent selects its children. |
