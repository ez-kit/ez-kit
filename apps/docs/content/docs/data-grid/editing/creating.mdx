# Creating Rows

The grid ships a "creating" flow: a trigger renders a button; clicking it opens a modal (or inline row) prepared with inputs derived from the columns' edit types.

## Usage

The creating flow supports three modes — an inline row at the bottom of the table, a modal dialog, or a blank row pinned to the top. Switch between them in the tabs below.

<DataGridDocsExample exampleId='creating' />

With per-field validation:

<DataGridDocsExample exampleId='creating-validation' />

```tsx
<DataGrid.CreateTrigger>New order</DataGrid.CreateTrigger>
<DataGrid.CreatingModal
	onSubmit={(draft) => api.create(draft)}
	defaultValues={{ status: 'pending' }}
/>
```

## Validation

Validators run before submit. Show inline errors next to the offending field; the modal will not close until validation passes.

```ts
{
	id: 'email',
	accessorKey: 'email',
	meta: {
		editable: true,
		editType: 'email',
		validate: (value) => emailSchema.safeParse(value).error?.issues[0]?.message,
	},
}
```
