# Inline Editing

Inline editing lets users update cells in place. Double-click a cell to enter edit mode, blur or Enter to commit, Escape to cancel.

## Usage

<DataGridDocsExample exampleId='base-editing' />

```tsx
const columns = defineColumns<User>([
	{
		id: 'email',
		accessorKey: 'email',
		meta: { editable: true, editType: 'email' },
	},
])

<DataGrid
	data={data}
	columns={columns}
	onCellEdit={({ rowId, columnId, value }) => updateRow(rowId, { [columnId]: value })}
/>
```

## Edit types

`meta.editType` picks the input rendered while editing: `'text'`, `'number'`, `'email'`, `'select'`, `'date'`, `'boolean'`. Custom edit types follow the same pattern as [Custom Cell Types](./data-grid/cells/custom-cell-types).
