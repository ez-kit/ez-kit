# Sticky Header

For tall tables, keep the header row pinned to the top of the scroll container while the body scrolls.

## Usage

Base sticky header:

<DataGridDocsExample exampleId='base-sticky' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	layout={{ stickyHeader: true, maxHeight: '32rem' }}
/>
```

`layout.maxHeight` bounds the scroll container — without a bound there is nothing for the header
to stick against. Omit it and the structural stylesheet's `400px` default applies.

`<DataGrid.Header />` reads `layout.stickyHeader` on its own, so a custom
[composition](./composition) keeps the sticky header with no extra wiring. Its `stickyHeader` prop
overrides the grid option for one header — useful when a hand-built `<DataGrid.Table>` body holds
more than one.

## Notes

- The "stickiness" is CSS — `position: sticky` on the `<thead>`. The grid sets `data-sticky="true"` on the header; flavor CSS handles the rest.
- Combine with [Row pinning](./data-grid/row-pinning) for sticky top rows beneath the header.
- Inside a virtualized body, sticky header still works — the scroll container is the same.
