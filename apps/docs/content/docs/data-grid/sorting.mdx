# Sorting

Click a column header to sort by it. Shift-click to add another column to the sort. Sorting is on for every accessor column by default.

## Options

| Option                     | Type                       | Description                                                                                                |
| -------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `enableSorting`            | `boolean`                  | Master switch. Default `true`.                                                                             |
| `enableMultiSort`          | `boolean`                  | Default `true`. Set `false` to allow only one sorted column at a time.                                     |
| `initialState.sorting`     | `SortingState`             | `[{ id, desc }]` — initial sort order.                                                                     |
| `state.sorting`            | `SortingState`             | Controlled sort state.                                                                                     |
| `onSortingChange`          | `(updater) => void`        | Subscribe to sort changes.                                                                                 |
| Per-column `enableSorting` | `boolean`                  | Disable sort on specific columns.                                                                          |
| Per-column `sortingFn`     | name \| `(a, b) => number` | Built-in: `'auto'`, `'alphanumeric'`, `'basic'`, `'datetime'`, `'text'`, etc. Or pass a custom comparator. |
