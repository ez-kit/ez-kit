Click a column header to sort by it. Shift-click to add another column to the sort. Sorting is on for every accessor column by default.

### Multi-sort builder

A multi-sort builder for selecting sort field + direction. It is a component, not an option:
mount `<DataGrid.SortMenuTrigger />` where you want it. No layout preset mounts it — `sorting`
alone means click-to-sort in the header, and the builder earns its place mostly with multi-column
sorting or more columns than the header shows.

<DataGridDocsExample exampleId='sort-toolbar' />

An entry's place in the builder is its **priority**: the sort above orders by department, then by
salary within each department. Each entry carries a pair of steps that moves it one place up or
down, so priority changes without removing an entry and adding it back. A step keeps the direction
of both entries it swaps.

With a [drag adapter](/docs/data-grid/drag-and-drop) bound, the steps give way to a grip, and an
entry is dragged straight to its new place — by pointer, or from the keyboard with `Space`, the
arrow keys and `Space` again. A screen reader hears the entry and its new priority:

<DataGridDocsExample exampleId='sort-builder-drag' />

`sorting.multi.reorderable` chooses the affordance with the same values the column surfaces take
(see [Ordering](/docs/data-grid/columns/ordering#the-arrows-or-the-drag-not-both)): `true`, the
default, means the grip with an adapter and the steps without one; `'step'`, `'drag'` and `'both'`
name it; `false` leaves the entries in the order they were added.

Under `manual: true` every step and every drop is one `onChange`, and so one request to the server.

**Add Sort** follows `multi`. Without multi-sort the builder holds one entry — the header click
replaces the sort rather than extending it, and so does the builder — and with `multi.max` it stops
at the cap. A column declared with `sorting: { multi: false }` is offered for the first entry only.

<DataGridDocsExample exampleId='sort-toolbar-single' />

The builder counts multi-sort as on only when `multi` is written. A Shift-click on a header still
extends the sort when it is not, as TanStack Table does by default — the builder then lists those
entries without steps or a grip, and **Add Sort** stays unavailable. Write `multi` to rank them.

## Options

### `sorting`

| Option      | Type                              | Description                                                                                                                                                                                                     |
| ----------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `manual`    | `boolean`                         | Disable client-side sorting. The grid calls `onChange` instead — see [Server-side Data](/docs/data-grid/state/server-side).                                                                                     |
| `descFirst` | `boolean`                         | Force the first click to sort descending. Unset, the direction is inferred per column from its first value: a **string** column starts ascending, every other type — number, date, boolean — starts descending. |
| `clearable` | `boolean`                         | Allow a third click to clear the sort. Default `true`.                                                                                                                                                          |
| `multi`     | `boolean \| MultiSortConfig`      | Multi-column sort. `false` (default) = single-column only; `true` = enabled with defaults.                                                                                                                      |
| `fns`       | `Record<string, SortingFn>`       | Named sort functions, addressable from column `sorting.fn` by id.                                                                                                                                               |
| `onChange`  | `(sorting: SortingState) => void` | Called when sort state changes.                                                                                                                                                                                 |
| `enabled`   | `boolean`                         | Explicit off-switch for a config that came from a defaults layer — the settings survive, the feature does not. Default `true`.                                                                                  |

### `MultiSortConfig`

| Option        | Type                            | Description                                                                                                                                      |
| ------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `max`         | `number`                        | Cap on simultaneously sorted columns. Unlimited by default.                                                                                      |
| `event`       | `'shift' \| 'ctrl' \| 'always'` | Gesture that engages multi-sort. Default `'shift'`.                                                                                              |
| `removable`   | `boolean`                       | Allow removing a single column from the multi-sort set. Default `true`.                                                                          |
| `reorderable` | `boolean \| ReorderMode`        | How the sort builder moves an entry: `'drag'`, `'step'`, `'both'`, or `false`. Default `true` — the grip with a drag adapter, the steps without. |

### Per-column `sorting`

| Option      | Type                                                   | Description                                                                                                                                                                                                  |
| ----------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `false`     | —                                                      | Disable sorting for this column.                                                                                                                                                                             |
| `descFirst` | `boolean`                                              | Overrides the table-level `sorting.descFirst` for this column.                                                                                                                                               |
| `fn`        | built-in name \| registry id \| `(a, b, id) => number` | Built-in: `'alphanumeric'`, `'alphanumericCaseSensitive'`, `'text'`, `'textCaseSensitive'`, `'datetime'`, `'basic'`. Or an id resolved from the table-level `sorting.fns` registry, or an inline comparator. |
| `undefined` | `'first' \| 'last' \| false`                           | Where `undefined` values land. Default `false` (treated as `0`).                                                                                                                                             |
| `invert`    | `boolean`                                              | Invert direction — useful for ranking columns where lower is "better".                                                                                                                                       |
| `multi`     | `boolean`                                              | Allow this column to participate in multi-sort. Default `true` (when multi enabled).                                                                                                                         |
