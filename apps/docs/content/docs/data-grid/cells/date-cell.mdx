# Date Cell

For date columns, the `'date'` cell type renders the value with `Date.prototype.toLocaleDateString`.

## Usage

The `date` cell type renders a locale-aware, formatted value and exposes date-aware filter operators (including a `between` range). Configure the display via `cell: { type: 'date', config: { format } }`, where `format` is an `Intl.DateTimeFormatOptions` object.

<DataGridDocsExample exampleId='date-cell-view' />

The same cell type doubles as an inline editor — with `editing: { variant: 'cell' }` a date picker opens on edit.

<DataGridDocsExample exampleId='date-cell-edit' />

And it powers the new-row form when `creating` is enabled, so authored dates go through the same picker.

<DataGridDocsExample exampleId='date-cell-create' />

```ts
{
	accessorKey: 'createdAt',
	header: 'Created at',
	cell: {
		type: 'date',
		config: {
			format: { dateStyle: 'medium' }, // Intl.DateTimeFormatOptions
			minValue: '2025-01-01',           // ISO 8601, hard minimum for the picker
			maxValue: '2027-12-31',           // ISO 8601, hard maximum for the picker
		},
	},
}
```

## Options

| `cell.config.*` | Type                         | Description                                                                            |
| --------------- | ---------------------------- | -------------------------------------------------------------------------------------- |
| `format`        | `Intl.DateTimeFormatOptions` | Forwarded to `Date.prototype.toLocaleDateString`. Omitted — locale-default formatting. |
| `minValue`      | `string` (ISO 8601)          | Hard minimum forwarded to the date-picker editor as a disabled-before bound.           |
| `maxValue`      | `string` (ISO 8601)          | Hard maximum forwarded to the date-picker editor as a disabled-after bound.            |
