# Date Cell

For date columns, the `'date'` cell type renders a locale-aware string and shows the full ISO timestamp on hover.

## Usage

The `date` cell type renders a locale-aware, formatted value and exposes date-aware filter operators (including a `between` range). Configure the display via `cell: { type: 'date', config: { format } }`.

<DataGridDocsExample exampleId='date-cell-view' />

The same cell type doubles as an inline editor — with `editing: { mode: 'cell' }` a date picker opens on edit.

<DataGridDocsExample exampleId='date-cell-edit' />

And it powers the new-row form when `creating` is enabled, so authored dates go through the same picker.

<DataGridDocsExample exampleId='date-cell-create' />

```ts
{
	id: 'createdAt',
	accessorKey: 'createdAt',
	meta: {
		cellType: 'date',
		format: 'PPp',          // e.g., "Apr 29, 2026, 11:00 AM"
		locale: 'en-US',
		tooltipFormat: 'PPPPpp', // long ISO-ish; shown on hover
	},
}
```

## Options

| `meta.*`        | Type      | Description                                                                                           |
| --------------- | --------- | ----------------------------------------------------------------------------------------------------- |
| `format`        | string    | Display format. Default depends on the active flavor's locale lib (`date-fns`-compatible by default). |
| `locale`        | string    | BCP-47 tag. Default reads from the browser.                                                           |
| `tooltipFormat` | string    | Hover format. Default is the full ISO timestamp.                                                      |
| `relative`      | `boolean` | When `true`, shows "2 days ago" instead of an absolute date.                                          |
