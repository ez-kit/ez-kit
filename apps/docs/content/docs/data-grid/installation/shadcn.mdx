# Install for shadcn

## 1. Install packages

```bash
pnpm add @ez-kit/data-grid-shadcn @ez-kit/data-grid-react @ez-kit/data-grid-core
```

The flavor (`@ez-kit/data-grid-shadcn`) re-exports everything you need at the call site; you import `data-grid-react` and `data-grid-core` only when you reach for hooks/types directly.

## 2. Import the stylesheet

Pull in the prebuilt CSS once at your app entry (`app/layout.tsx`, `_app.tsx`, `main.tsx`, etc.):

```ts
import '@ez-kit/data-grid-shadcn/global.css'
```

This stylesheet defines the CSS tokens and `data-*` selectors that the flavor's components rely on. You can override any of them from your own design tokens — see [Theming](./data-grid/theming).

## 3. Render a grid

The example below is the published surface, locked to shadcn.

<DataGridDocsExample
	exampleId='base-plain'
	defaultType='shadcn'
	lockFlavor
/>

That's it — sort, filter, paginate, and select all work out of the box. Branch out from [Getting Started → Next steps](./data-grid/getting-started#3-next-steps) for the per-capability deep dive.
