# Row Pinning

Pinned rows stay anchored to the top or bottom of the table. Useful for summary rows, "you are here" markers, or recently-edited rows.

## Usage

Pinning is demonstrated in a scrollable container with a sticky header — this is what makes the pin effect visible: pinned rows stay stuck to the top or bottom as the rest of the table scrolls underneath.

<DataGridDocsExample exampleId='row-pinning-sticky-header' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	pinning={{ row: { top: true, bottom: true } }}
/>
```

## Options

| Option                    | Type                                             | Description                                                                                                                                 |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `pinning.row` (table)     | `boolean \| { top?: boolean, bottom?: boolean }` | Enables row pinning. `true` — top+bottom. `{ top: true }` — top only, etc. Once enabled, the grid renders a per-row pin control.            |
| `state.rowPinning`        | `{ top?: string[], bottom?: string[] }`          | Controlled pinning state — pass alongside `onStateChange`. No per-feature `onChange`; see [Controlled State](./data-grid/controlled-state). |
| `initialState.rowPinning` | same                                             | Uncontrolled seed for pinned rows at mount.                                                                                                 |
| `getRowId`                | `(row: TRow, index: number) => string`           | Recommended for stable pinning across data refreshes.                                                                                       |
