# Row Pinning

Pinned rows stay anchored to the top or bottom of the table. Useful for summary rows, "you are here" markers, or recently-edited rows.

## Usage

Pinning is demonstrated in a scrollable container with a sticky header — this is what makes the pin effect visible: pinned rows stay stuck to the top or bottom as the rest of the table scrolls underneath.

<DataGridDocsExample exampleId='row-pinning-sticky-header' />

```tsx
<DataGrid
	data={data}
	columns={columns}
	pinning={{ row: { top: true, bottom: true } }}
/>
```

The pin control lives in the row actions column, next to edit and delete — see [Row actions](./data-grid/row-actions). Enabling row pinning is enough to create that column; you do not need editing or deleting.

## Options

| Option                    | Type                                    | Description                                                                                                                                                                         |
| ------------------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pinning.row` (table)     | `boolean \| RowPinningConfig`           | Enables row pinning. `true` — top+bottom. `{ top: true }` — top only, etc. Once enabled, the grid renders a per-row pin control.                                                    |
| `pinning.row.onChange`    | `(rowPinning: RowPinningState) => void` | Called whenever row pinning changes. Use it to persist which rows a user pinned.                                                                                                    |
| `state.rowPinning`        | `{ top?: string[], bottom?: string[] }` | Controlled pinning state — pass alongside `onStateChange`. See [Controlled State](./data-grid/controlled-state).                                                                    |
| `initialState.rowPinning` | same                                    | Uncontrolled seed for pinned rows at mount.                                                                                                                                         |
| `getRowId`                | `(row: TRow, index: number) => string`  | Only needed when the primary key is not `row.id` — the default already keys on it (falling back to the row index when it is missing), so pinning survives a refetch out of the box. |
