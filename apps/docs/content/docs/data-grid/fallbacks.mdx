---
title: Fallbacks
description: Loading, empty, and no-results states — three slots the grid renders when there's nothing else to show.
---

The grid distinguishes three "nothing to show" states and gives each its own slot:

- **Loading** — initial fetch, refresh, or while controlled `state.loading` reports a pending or in-flight request.
- **Empty** — the data set is genuinely empty (no rows at all).
- **No results** — the data set has rows, but filters/search excluded them all.

## Usage

Fallbacks render automatically whenever the grid has no visible rows. Switch between the states below to preview each slot.

<DataGridDocsExample exampleId='fallbacks' />

```tsx
<DataGrid.LoadingBody />
<DataGrid.EmptyStateRow>
	No orders yet. <button>Create one</button>
</DataGrid.EmptyStateRow>
<DataGrid.NoResultsRow>
	No matching rows. <DataGrid.ClearFiltersButton />
</DataGrid.NoResultsRow>
```

## Loading

Pass `state.loading` (see [Controlled State](/docs/data-grid/state/controlled)) — the grid renders `<LoadingBody />` instead of rows. The slot is a `LoadingState` object, not a boolean: `isPending` is the initial load, `isFetching` a refetch, and `isError` / `error` the last failure.

Name only the fields you have. A list loaded once needs nothing but `isPending`; the flags you leave out read as `false` and `error` as `null`:

```tsx
<DataGrid
	features={features}
	data={data}
	columns={columns}
	state={{ loading: { isPending } }}
/>
```

A TanStack Query result carries all four fields, so it passes through whole — `state={{ loading: query }}`. The grid keeps only those four. An SWR response does not: it has `isLoading` and `isValidating` instead, so map them onto `isPending` / `isFetching`. Passed whole, it would never show a loading state, and the grid warns about it in development.

The loading fallback is **centered** in the body area.

## Empty vs No results

The grid picks between them automatically and there is no state override: **empty** renders when `data` itself is empty and nothing is loading, **no results** when filters reduce a non-empty data set to zero rows.

What you can configure is each slot, via `fallbacks`. Pass `false` to disable one, or `{ component }` to replace what it renders — `component` takes a `ReactElement` (rendered as-is) or a `ComponentType` (called via `flexRender`):

```tsx
<DataGrid
	features={features}
	data={data}
	columns={columns}
	fallbacks={{
		loading: true,
		empty: { component: <p>No orders yet</p> },
		noResults: false,
	}}
/>
```
