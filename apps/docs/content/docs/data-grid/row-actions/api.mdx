The reference for [Row actions](/docs/data-grid/row-actions) — what each option does is explained
there, with a live example beside it.

## Options

| Option                 | Type                                  | Description                                                                                                                                                                  |
| ---------------------- | ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rowActions.placement` | `'inline' \| 'menu'`                  | Where the built-in edit / delete pair lives. `inline` (default) — one icon button each. `menu` — both in the one dropdown. See [Layout](/docs/data-grid/row-actions#layout). |
| `rowActions.actions`   | `({ row, table }) => RowActionItem[]` | Custom entries added to the built-ins, built per row. See [Custom actions](/docs/data-grid/row-actions#custom-actions).                                                      |
| `rowActions.column`    | `SystemColumnDef`                     | The actions column itself — its header, width, pinning. See [The column itself](#the-column-itself).                                                                         |
| `rowActions.enabled`   | `boolean`                             | Explicit off-switch for a config that came from a defaults layer — the settings survive, the feature does not. Default `true`.                                               |

## Entry shape

One entry of `rowActions.actions` — and of
[`selection.bar.actions`](/docs/data-grid/selection/selection-bar#custom-actions), which takes the
same shape bar the last two rows. An entry either describes itself with the fields above
`component`, or hands over its markup through `component` and carries nothing else but `id`.

`placement` and `width` are the row's own: a cell has two containers to choose between, while every
entry in the selection bar is already a button.

| Field         | Type                 | Description                                                                                                                                                                               |
| ------------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`          | `string`             | Required. Stable within the menu. Namespaced internally, so it cannot collide with a built-in action.                                                                                     |
| `label`       | `string`             | Required. The wording rendered in the menu, and the accessible name of an inline button.                                                                                                  |
| `icon`        | `ReactElement`       | Your own element — `icon: <Copy />`. Optional in the menu; **required** under `placement: 'inline'`, where there is nothing else to draw.                                                 |
| `className`   | `string`             | Class applied to whatever the kit draws for the entry — the menu entry, or the inline button.                                                                                             |
| `disabled`    | `boolean`            | Renders the entry inert.                                                                                                                                                                  |
| `destructive` | `boolean`            | Renders the entry in the kit's destructive colour, like the built-in Delete.                                                                                                              |
| `onAction`    | `() => void`         | Required. Runs when the entry is chosen — by click, by Enter / Space, or by menu typeahead.                                                                                               |
| `component`   | `ReactElement`       | Alternative to every field above bar `id`: your own markup for the entry. See [Drawing an entry yourself](/docs/data-grid/row-actions#drawing-an-entry-yourself).                         |
| `placement`   | `'inline' \| 'menu'` | **Row actions only.** `menu` (default) — the entry joins the overflow menu. `inline` — it becomes a button in the cell. See [Inline entries](/docs/data-grid/row-actions#inline-entries). |
| `width`       | `number`             | **Row actions only**, and only beside `component` + `placement: 'inline'`: how wide that markup is, in px. Defaults to one button (32px) and warns.                                       |

## The column itself

`selection`, `expanding` and `rowActions` each inject a column, and each takes a `column`
option describing it — with the same names, and the same scalar-or-object forms, an ordinary
column uses.

| Option            | Type                                                          | Description                                                                                                                            |
| ----------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `header`          | `string \| (ctx) => ReactNode`                                | Header content. Omitted, the column keeps its built-in header — the select-all checkbox for selection, nothing for expand and actions. |
| `width`           | `number \| { default?, min?, max? }`                          | Width in pixels. Defaults: `44` for selection and expand, a derived width for actions.                                                 |
| `pinning`         | `false \| 'left' \| 'right' \| { side?, initialSide? }`       | Which viewport edge it sticks to. Defaults: `'left'` for selection and expand, `'right'` for actions.                                  |
| `align`           | `'start' \| 'center' \| 'end' \| { header?, cell?, footer? }` | Horizontal alignment. Logical, like a normal column's `align`.                                                                         |
| `headerClassName` | `string`                                                      | Class applied to the header cell.                                                                                                      |
| `cellClassName`   | `string`                                                      | Class applied to the body cells.                                                                                                       |

```tsx
<DataGrid
	data={rows}
	columns={columns}
	deleting={{ onDelete }}
	rowActions={{ column: { header: 'Actions', width: 120, pinning: false } }}
/>
```
