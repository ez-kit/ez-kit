# Column Visibility

Let users toggle which columns are visible. Hidden columns retain their filter and sort state — re-showing a column doesn't reset it.

## Usage

<DataGridDocsExample exampleId='column-visibility' />

The grid exposes a `column-visibility-trigger` slot that renders the kit's menu component. Hidden columns are computed from the engine's visibility state.

```ts
const table = useDataGrid({ data, columns })
table.setColumnVisibility({ email: false })
```

For a minimal toggle without the menu, use the same control directly via column id:

```ts
table.getColumn('email')?.toggleVisibility(false)
```

## Options

| Option                          | Type                               | Description                                                                                                                                                                                         |
| ------------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `visibility`                    | `false \| { initialHidden: true }` | Per-column. `false` disables hiding — the column is always visible (no Hide option in its menu, absent from the Columns toggle). `{ initialHidden: true }` starts the column hidden but toggleable. |
| `state.columnVisibility`        | `Record<string, boolean>`          | Controlled visibility state (passes through to `useDataGrid`).                                                                                                                                      |
| `initialState.columnVisibility` | `Record<string, boolean>`          | Hidden columns at mount. Merges with the column-level `initialHidden` seeds — see below.                                                                                                            |

Column visibility has no dedicated `onChange` — subscribe via the single `onStateChange` callback (see [Controlled State](./data-grid/controlled-state)).

## Seeds and invariants

`initialState.columnVisibility` **merges** with the `initialHidden` seeds from the column defs
rather than replacing them: a column you do not mention stays hidden, one you do mention takes your
value.

`visibility: false` is an invariant, not a seed. Such a column can never be hidden — not by
`initialState`, not by controlled `state`, not by `table.setState`. Its menu has no Hide option and
it is absent from the Columns toggle, so a state that hid it could never be undone by the user. The
system columns (`__selection__`, `__expand__`, `__actions__`) are covered by the same rule.

See [State model](./data-grid/state-model) for the full precedence.
