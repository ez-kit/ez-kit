# Column Helper

`createColumnHelper<TRow>()` returns a builder that gives you typed column factories — you get autocomplete on accessor keys, inferred cell types, and a clean place to register meta/options.

## Base usage

<DataGridDocsExample exampleId='column-helper' />

```ts
import { createColumnHelper } from '@ez-kit/data-grid-react'

const helper = createColumnHelper<User>()

const columns = [
	helper.accessor('name', { header: 'Name' }),
	helper.accessor('email', { header: 'Email' }),
	helper.display({ id: 'actions', cell: ({ row }) => <RowMenu row={row} /> }),
]
```

## Registered cell types

When a column declares a registered cell-type id in `meta`, the engine resolves the renderer from the registry. See [Custom Cell Types](./data-grid/cells/custom-cell-types) for how to register one.

<DataGridDocsExample exampleId='column-helper-registered' />

## Options

| Option | Type | Description |
| --- | --- | --- |
| `helper.accessor(key, def)` | builder | Typed accessor column. `key` is `keyof TRow`. |
| `helper.display(def)` | builder | Display-only column (no accessor); cell renderers are required. |
| `helper.group(def)` | builder | Header group containing nested columns. |
| `meta.cellType` | `string` | If the column should be rendered by a registered cell type, set this id. |
