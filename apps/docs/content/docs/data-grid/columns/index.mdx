# Columns

Columns are the backbone of the grid. They tell the engine what data to read from each row, how to render it, and which behaviors (sorting, filtering, pinning, etc.) to enable.

## Usage

This grid combines visibility, pinning, and resizing: drag column borders to resize, pin a column from its ⋮ menu, and toggle columns through the **Columns** button. The **Active** column starts hidden.

<DataGridDocsExample exampleId='columns-combined' />

You define columns once and pass them to the grid's `columns` prop. Most columns are accessor columns — they read a row property by key and render a value.

```ts
import { createColumns } from '@ez-kit/data-grid-react'

const columns = createColumns<User>([
	{ id: 'name', header: 'Name', accessorKey: 'name' },
	{ id: 'email', header: 'Email', accessorKey: 'email' },
	{ id: 'status', header: 'Status', accessorKey: 'status' },
])
```

For typed accessors, custom rendering, and registered cell types, prefer the [column helper](./data-grid/columns/column-helper).

## Options

| Option                         | Type                                                                   | Description                                                                                                                                                                                                                                                                    |
| ------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                           | `string`                                                               | Stable column identifier. Required when no `accessorKey` is given.                                                                                                                                                                                                             |
| `accessorKey`                  | `keyof TRow`                                                           | Reads a row property by name.                                                                                                                                                                                                                                                  |
| `accessorFn`                   | `(row: TRow, index: number) => unknown`                                | Computed accessor; takes the whole row and its index.                                                                                                                                                                                                                          |
| `header`                       | `string`                                                               | Header label.                                                                                                                                                                                                                                                                  |
| `cell`                         | `CellDef` — `{ type?, config?, component? }`                           | Cell display and input config. Pick a built-in `type` (`text`, `number`, `date`, `boolean`, `select`, `badge`, `image`, `link`, `progress`, or a registered custom id) with per-type `config`, or supply a custom `component`. See [Cell types](./data-grid/cells/cell-types). |
| `sorting`                      | `false \| ColumnSortingConfig`                                         | Column-level sorting. `false` disables sorting for this column; an object fine-tunes `descFirst`, `fn`, `undefined`, `invert`, `multi`.                                                                                                                                        |
| `pinning`                      | `false \| { pin?: 'left' \| 'right'; defaultPin?: 'left' \| 'right' }` | Column-level pinning. `pin` — static, always pinned, no pin section in the column menu. `defaultPin` — starts pinned, user can change it via the menu. See [Column Pinning](./data-grid/columns/column-pinning).                                                               |
| `enableColumnFilter`           | `boolean`                                                              | Default `true`.                                                                                                                                                                                                                                                                |
| `enableHiding`                 | `boolean`                                                              | Default `true`.                                                                                                                                                                                                                                                                |
| `size` / `minSize` / `maxSize` | `number`                                                               | Column-width constraints when resizing is enabled.                                                                                                                                                                                                                             |
