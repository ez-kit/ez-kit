# Resizing

Enable drag-to-resize on column borders. Double-click a border to reset a column, and note that the **Active** column has resizing disabled.

## Usage

The two grids below contrast the resize modes: **onChange** updates widths live during the drag, while **onEnd (performant)** commits the new width only on mouse release, avoiding re-renders mid-drag.

<DataGridDocsExample exampleId='resizing' />

```ts
const grid = useDataGrid({
	data,
	columns,
	enableColumnResizing: true,
	columnResizeMode: 'onChange', // or 'onEnd'
})
```

## Options

| Option | Type | Description |
| --- | --- | --- |
| `enableColumnResizing` | `boolean` | Master switch. Default `false`. |
| `columnResizeMode` | `'onChange' \| 'onEnd'` | `'onChange'` (default) updates sizes during the drag; `'onEnd'` commits once on mouseup. Use `'onEnd'` for very wide tables where re-layout cost matters. |
| Per-column `size` / `minSize` / `maxSize` | `number` | Constrain individual columns. |
| `state.columnSizing` | `Record<string, number>` | Controlled sizing state. |
| `onColumnSizingChange` | `(updater) => void` | Subscribe to size changes for persistence. |
